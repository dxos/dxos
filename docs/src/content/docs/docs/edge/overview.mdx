EDGE is an always-online peer for local-first apps, run by DXOS on Cloudflare Workers.

In a client-server app, the data lives on the server. EDGE is not where the data lives. The devices are. EDGE does
four jobs for them:

- It keeps a copy of each space that replicates through it.
- It indexes that copy, if the space lets EDGE read it.
- It recovers identities when every device is lost.
- It runs operations and agents while every device is asleep, on the spaces it can read.

EDGE can read a space only when the space gives it more than `pull` access. See HALO's
[Spaces and membership](/docs/halo/concepts/spaces-membership/).

Each space and each identity gets its own Durable Objects. A Durable Object is a small stateful server, and these hold
that space's or identity's state.

## What goes over each link

<Diagram name="edge-overview" alt="Two devices share a direct link and each keep a WebSocket to the Router in EDGE; the Router reaches the DB, compute and identity services, the DB service fires triggers in compute, and compute prompts the AI service." />

Every device keeps one WebSocket to EDGE. Over that WebSocket, EDGE does four things:

- It introduces the device to its peers.
- It receives and sends the changes for each of the device's spaces that replicate through it.
- It answers queries over objects the device has not loaded, in the spaces it can read.
- It runs the identity's services.

Devices that are online together also link directly through [MESH](/docs/mesh/overview/).

## Running it

DXOS runs EDGE. You point your app at it with one setting, `runtime.services.edge.url`. In production, the value is
`https://dxos.network/`. There is no self-hosted EDGE. See [Configuration](/docs/edge/resources/configuration/).

## How these pages are organized

Your app reaches EDGE through the DXOS client, not through an API you call. These pages explain how EDGE works, so
there is no learning path, API group or guides.

- [Why EDGE?](/docs/edge/why-edge/) argues for servers in a local-first system.
- [Architecture](/docs/edge/concepts/architecture/) lists the services and the objects behind them. The other concept
  pages take one job each.
