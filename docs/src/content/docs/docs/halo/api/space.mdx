`Space` manages spaces as units of membership. Use it to say which spaces exist, who belongs to each and what they may
do.

`Space` does not read or write the data inside a space. That is ECHO's [Database](/docs/echo/api/database/), which you
reach by the same space id.

Every function needs `Space.Service`, which `layerClient` provides along with `Identity.Service`.

## List spaces

`Space.spaces` is a stream of the spaces the identity belongs to. It emits the current list straight away, so take one
value to read it once. `Space.get` looks one up by id.

`membershipPolicy: 'locked'` creates a space no one else can join.

## Members

`members` is a stream of the member list. Each member has a DID, a display name, an access level (`role`) and whether
it is online.

`updateMemberRole` changes a member's access, and `removeMember` revokes it. Both take the member's DID. Both need
`admin`, or [causal seniority](/docs/halo/concepts/spaces-membership/) to revoke.

## Archives and EDGE replication

`exportSpace` writes the space to an archive, and `importSpace` creates a new space from one.

`setEdgeReplication` turns replication through [EDGE](/docs/edge/concepts/replication/) on or off. With it off, the
space syncs only between peers that are online together.

## Members at a glance

| Member                                  | Summary                                         |
| --------------------------------------- | ----------------------------------------------- |
| `Service`                               | The Effect service                              |
| `spaces` `get`                          | The identity's spaces                           |
| `create` `waitReady`                    | Make a space and wait until it is ready         |
| `members`                               | The member list as a stream                     |
| `updateMemberRole` `removeMember`       | Change a member's access                        |
| `share` `join` `invitations`            | Space invitations                               |
| `exportSpace` `importSpace`             | Archives                                        |
| `setEdgeReplication`                    | Sync through EDGE, or only peer to peer         |

The full list is in the [API reference](/docs/halo/resources/api-reference/).

## Errors

Every function that can fail fails with `SpaceError`, whose message says what went wrong. Handle it by its tag:

<Snippet file="halo-guide-space" region="errors" />

Here, `safeRemove` catches the error from `remove` and logs its message.

A membership change Keyhive refuses names the reason with one of the errors `@dxos/halo` exports:

| Error                    | Raised when                                                              |
| ------------------------ | ------------------------------------------------------------------------ |
| `NotAuthorizedError`     | The acting member lacks the access, such as revoking without seniority   |
| `UnknownPrincipalError`  | The member named is not known to the space                               |
| `InvalidSignatureError`  | A signed operation fails verification                                    |
| `MissingDependencyError` | An operation refers to earlier operations that have not arrived          |
