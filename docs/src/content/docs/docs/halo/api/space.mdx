`Space` manages spaces as units of membership. Use it to create spaces, to list them, and to decide who belongs to
each and what they may do.

`Space` does not read or write the data inside a space. That is ECHO's [Database](/docs/echo/api/database/), which you
reach by the same space id.

Every function needs `Space.Service`, which `layerClient` provides along with `Identity.Service`.

## List spaces

`Space.spaces` is a stream of the spaces the identity belongs to. It emits the current list straight away, so take one
value to read it once. `Space.get` looks one up by id.

`space.name` is `undefined` for a space that is not ready yet, because a space reports its name only once it is ready.
`findSpace` turns the `Option` from `Space.get` into the space or `undefined`.

## Create a space

`Space.create` returns the new space's id, name and state. Wait for `Space.waitReady` before you open its database.
Pass `membershipPolicy: 'locked'` to create a space no one else can join.

## Members

`Space.members` is a stream of the member list. Each member has a DID, a display name, an access level and whether it
is online. The API calls the access level `role`.

`Space.updateMemberRole` changes a member's access level. Use it to raise or lower what a member may do. It takes
`read`, `edit` or `admin`, and it fails for `pull`.

`Space.removeMember` revokes a member's access. Both functions take the member's DID. Both need `admin`, or
[causal seniority](/docs/halo/concepts/spaces-membership/) to revoke.

## Share and join

`Space.share` starts a space invitation and `Space.join` accepts one. Both return an
[`Invitation.Flow`](/docs/halo/api/invitation/).

The guest joins as an `admin`. With no options, `share` admits anyone who has the invitation code, so pass
`authMethod: 'shared-secret'` unless you control every screen the code appears on.

**Example** (Inviting someone to a space, and accepting)

<Snippet file="halo-guide-space" region="share" />

`invite` runs on the host, and `accept` runs on the guest with the code that `invite` logged.
[Invitation](/docs/halo/api/invitation/) drives the two flows from there.

## Archives and EDGE replication

`Space.exportSpace` writes the space to an archive, and `Space.importSpace` creates a new space from one.

`Space.setEdgeReplication` turns replication through [EDGE](/docs/edge/concepts/replication/) on or off. With it off,
the space syncs only between peers that are online together.

## Members at a glance

| Member                                  | Summary                                         |
| --------------------------------------- | ----------------------------------------------- |
| `Service`                               | The Effect service                              |
| `spaces` `get`                          | The identity's spaces                           |
| `create` `waitReady`                    | Make a space and wait until it is ready         |
| `members`                               | The member list as a stream                     |
| `updateMemberRole` `removeMember`       | Change or revoke a member's access level        |
| `share` `join` `invitations`            | Space invitations                               |
| `exportSpace` `importSpace`             | Archives                                        |
| `setEdgeReplication`                    | Sync through EDGE, or only peer to peer         |

The full list is in the [API reference](/docs/halo/resources/api-reference/).

## Errors

Every function that can fail fails with `SpaceError`. Handle it by its tag:

<Snippet file="halo-guide-space" region="errors" />

`error.message` says only that a space operation failed, so `safeRemove` logs `error.context.error` instead.

`@dxos/halo` also exports four errors that name why Keyhive refuses a membership change. None of them is in the error
type of `removeMember` or `updateMemberRole`, which is `SpaceError`:

| Error                    | Raised when                                                              |
| ------------------------ | ------------------------------------------------------------------------ |
| `NotAuthorizedError`     | The acting member lacks the access, such as revoking without seniority   |
| `UnknownPrincipalError`  | The member named is not known to the space                               |
| `InvalidSignatureError`  | A signed operation fails verification                                    |
| `MissingDependencyError` | An operation refers to earlier operations that have not arrived          |
