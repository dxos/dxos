This guide wires HALO into a React app. At the end, your components show the identity, its devices, its spaces and
their members, and follow an invitation.

`@dxos/halo-react` reads HALO from React components. Each hook follows one `@dxos/halo` stream and re-renders when it
emits. This means a component shows the current identity, devices or members without subscribing itself.

## Set up the provider

`HaloProvider` takes the HALO services as an Effect `Context`. Build the context from a `Client` with the adapter's
`makeIdentityService` and `makeSpaceService`. Then wrap the part of the app that uses the hooks.

## The identity

`useIdentity` returns the identity, or `undefined` before one exists. It has the current value on the first render.
`useDevices` and `useCredentials` return the identity's devices and credentials.

Here, `Profile` renders a placeholder until an identity exists. It then shows the display name, the number of devices
and the number of recovery credentials that are not revoked.

## Spaces and members

`useSpaces` returns the spaces that are ready. Pass `{ all: true }` when you want every space. `useSpace` finds one by
id, and `useMembers` returns a space's members.

In this example, `SpaceList` renders one `Members` for each space. `Members` shows the space's name and each member's
display name, or the DID when a member has no display name.

## Invitations

Start a flow with `Space.share` or `Identity.share`, run as an Effect with the same services.

`useInvitationFlow` follows the flow, and returns its latest event and its code. It needs no provider, because a flow
carries what it needs.

`useSpaceInvitations` and `useHaloInvitations` list the flows this device has open.

## Hooks at a glance

| Hook                                       | Returns                                       |
| ------------------------------------------ | --------------------------------------------- |
| `useIdentity`                              | The identity, or `undefined`                  |
| `useDevices` `useCredentials`              | The identity's devices and credentials        |
| `useSpaces` `useSpace`                     | Spaces, and one space by id                   |
| `useMembers`                               | A space's members                             |
| `useContacts`                              | Everyone you share a space with, once each    |
| `useSpaceInvitations` `useHaloInvitations` | Open space and device invitations             |
| `useInvitationFlow`                        | One flow's latest event and code              |
