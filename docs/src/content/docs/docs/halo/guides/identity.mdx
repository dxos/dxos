`Identity` manages the user on this device: the identity itself, its profile, its devices, its recovery credentials and
the credentials it grants to services. Every function is an Effect or a Stream that needs `Identity.Service`.

## Get the service

`layerClient` from `@dxos/halo-adapter-client` provides `Identity.Service` and `Space.Service` from a `Client`. Effect code
can also ask for the service directly when it needs the synchronous methods.

## Read the identity

`getSnapshot` reads it once, as an `Option` that is empty before an identity exists. `identity` is a stream that emits the
current value, then each change.

<Snippet file="halo-create-identity" region="follow" />

## Create an identity and update its profile

`create` generates the key pair and stores it on the device. `updateProfile` changes the display name and any profile
data, such as an avatar.

## Devices

`getDevicesSnapshot` and `devices` list the identity's devices. To add one, `share` starts a device invitation and `join`
accepts it on the new device. Both return an [`Invitation.Flow`](/docs/halo/guides/invitation/).

## Recovery credentials

`createRecoveryCredential` with no options returns a recovery code. Pass `externalKey` to register a passkey instead.
`recover` admits a new device with a recovery code, a passkey assertion or an OAuth token, and
`revokeRecoveryCredential` withdraws a credential by its lookup key.

<Snippet file="halo-recover" region="create" />

<Snippet file="halo-recover" region="recover" />

<Snippet file="halo-recover" region="revoke" />

## Service access and API tokens

`grantServiceAccess` writes a credential that lets the identity use an EDGE or Hub service. `createApiToken` mints a token
a CLI or a server can use to act as the identity. The token's secret is returned once, so store it straight away.

<Snippet file="halo-guide-identity" region="access" />

## Members at a glance

| Member                                                     | Summary                                          |
| ---------------------------------------------------------- | ------------------------------------------------ |
| `Service`                                                  | The Effect service                               |
| `getSnapshot` `identity`                                   | The identity, once or as a stream                |
| `create` `updateProfile`                                   | Make the identity and edit its profile           |
| `personalSpaceId`                                          | The identity's personal space                    |
| `getDevicesSnapshot` `devices`                             | The identity's devices                           |
| `share` `join` `invitations`                               | Device invitations                               |
| `createRecoveryCredential` `recover` `revokeRecoveryCredential` | Recovery                                    |
| `credentials`                                              | The credentials the identity holds               |
| `grantServiceAccess` `createApiToken`                      | Access to EDGE and Hub services                  |

The full list is in the [API reference](/docs/halo/resources/api-reference/).
