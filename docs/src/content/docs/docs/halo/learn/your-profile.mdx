## Background

An identity stands for you. In Keyhive, which HALO is built on, it is a group named by a DID, such as
`did:halo:BA25QRC2…`. Its members are your devices, and the first member is the device that creates it. No server issues
the identity; the client makes it on the device, with no network needed.

The identity also has a profile: a display name, and any other data the app wants, such as an avatar. Everyone you share a
space with sees it.

The code is Effect. `@dxos/halo` describes each operation as an `Effect` or a `Stream` that needs `Identity.Service` or
`Space.Service`. `@dxos/halo-adapter-client` makes both from a client, and `@dxos/halo-react` hands them to the
components through React context, with hooks that follow the streams.

## Steps

<Steps>

1. **Install the packages.** `@dxos/client` holds the client, `@dxos/halo` the API these pages use,
   `@dxos/halo-adapter-client` the services between them, and `@dxos/halo-react` the provider for React. Until the next npm release, install the build of main these pages
   describe, from pkg.pr.new.

   <Tabs>
     <TabItem label="pnpm">
       ```bash
       pnpm add https://pkg.pr.new/dxos/dxos/@dxos/client@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo-adapter-client@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo-react@20a14b9 effect@4.0.4
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install --save https://pkg.pr.new/dxos/dxos/@dxos/client@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo-adapter-client@20a14b9 https://pkg.pr.new/dxos/dxos/@dxos/halo-react@20a14b9 effect@4.0.4
       ```
     </TabItem>
   </Tabs>

   The browser setup is the same as ECHO's; see [Installation](/docs/echo/learn/installation/) for the Vite config. The
   StackBlitz project has it already.

2. **Configure the client.** The client keeps the device's keys and data on the device, and reaches other devices through
   EDGE, DXOS's network, which relays invitations and replicates spaces.

   <Snippet file="halo-tutorial/app/App" region="config" lang="tsx" />

3. **Start the client.** `openHalo` starts a client and returns it with the HALO services it backs. The app calls it
   once, at startup, and puts the services in a `HaloProvider`. Below it, a component gets them with `useHaloServices()`
   and runs each piece of HALO code with `Effect.provide(services)` and `Effect.runPromise`.

   <Snippet file="halo-tutorial/app/App" region="client" lang="tsx" />

4. **Create your identity.** `Identity.create` makes the identity, with this device as its first member, and gives its
   profile your name. **Start** on the welcome screen calls this.

   <Snippet file="halo-tutorial/app/Welcome" region="create" lang="tsx" />

5. **Follow your identity.** `useIdentity` returns the identity, or `undefined` before there is one, and re-renders the
   component on every change. It follows `Identity.identity`, a stream of the identity. The contact book reads it to show
   either the welcome screen or your name.

   <Snippet file="halo-tutorial/app/ContactBook" region="follow" lang="tsx" />

6. **Change your profile.** `Identity.updateProfile` writes a new profile. `useIdentity` re-renders with it, and so does
   every space member list that includes you. Clicking your name, then **Save**, calls this.

   <Snippet file="halo-tutorial/app/Profile" region="rename" lang="tsx" />

</Steps>

## Try it

This device has no identity yet. Type a name and press **Start**, then click your name to change it.
