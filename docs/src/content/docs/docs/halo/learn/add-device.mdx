By the end of this page the tutorial app runs on two devices that belong to one user, and lists them both.

## Background

A device here is one client's storage: a browser profile on one site, or one Node process. Each has its own key. Adding
a device means the identity authorizes the new device's key, after which the device can act for the user and replicate
their spaces. Nothing is copied by hand; the new device syncs once it is admitted.

The admission is a device invitation. The device that already has the identity shares it, and the new device joins with
the invitation code. To prove the person at the new device is the same one, the first device shows a short authorization
code, and the person types it on the new device. [Invitations](/docs/halo/concepts/invitations/) explains the flow.

## Steps

1. **Share the identity from the first device.** `Identity.share` starts the invitation and returns its flow. Read the
   invitation code from the flow, and watch its events for the authorization code.

   <Snippet file="halo-add-device" region="share" />

   The console shows the invitation code. When the second device connects, it also shows a short authorization code.

2. **Join from the second device.** `Identity.join` takes the invitation code. When the flow is ready for authentication,
   `Invitation.authenticate` sends the authorization code back.

   <Snippet file="halo-add-device" region="join" />

   Both flows end with a `success` event. The second device now has the same DID as the first.

3. **List the devices.** Each entry has the device's kind, such as `browser` or `native`, and whether it is online.
   `current` marks the device the code runs on.

   <Snippet file="halo-add-device" region="devices" />

   The list shows both devices. `Identity.devices` is the same list as a stream, for a page that stays open.

## Recap

You can now:

- Share an identity and read the invitation and authorization codes.
- Join a new device with those codes.
- List the identity's devices, with their kind and presence.

Next, [invite a member](/docs/halo/learn/invite-member/): another person, with an identity of their own, into the app's
space.
