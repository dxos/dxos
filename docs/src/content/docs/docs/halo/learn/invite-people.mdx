By the end of this page Alice can invite Bob into Book club, and Bob joins with two codes: one she sends him and one she
tells him.

## Background

On most sites, an invitation is a link, and whoever opens the link gets in. A HALO invitation has two sides and, the
way we set it up here, two codes.

The **host** is the device that starts the invitation, which is Alice's. The **guest** is the device that redeems it,
which is Bob's. The two codes travel by different routes:

- The **invitation code** is long and goes in a message or a link.
- The **authorization code** is six digits. The host sees it once the guest connects, and passes it on another way,
  such as reading it aloud.

Someone who intercepts only the message holds one code of the two, and cannot get in.

When the guest enters the right authorization code, in step 4, the two sides exchange **contact cards**. Each card
names its sender's identity and carries the keys the other side needs.

Then the host writes a **delegation**, a signed statement that admits the guest to the space. Every member checks
that delegation for itself, so no server has to vouch for the guest. The guest joins as an admin, like the host.

In code, each side holds a **flow**, a handle for the invitation in progress. Its events say where the handshake is:
`connecting`, `connected`, `readyForAuthentication`, `authenticating`, then `success`, `cancelled` or `error`. We
follow them in step 3. [Invitations](/docs/halo/concepts/invitations/) covers the rest.

## Steps

<Steps>

1. **Invite someone.** **Invite** calls `handleInvite` for the current space. `Space.share` starts the invitation on
   the host, and `Invitation.code` returns the invitation code to send.

   <Snippet file="halo-tutorial/app/Invitations" region="invite" lang="tsx" />

   `authMethod: 'shared-secret'` is the line to get right, because it is what makes the guest enter the authorization
   code. Without it, `Space.share` asks for no proof, and anyone who sees the invitation code can join.

2. **Join.** On the guest, **Join** calls `handleJoin` with the pasted invitation code. `Space.join` redeems it and
   returns the guest's own flow.

   <Snippet file="halo-tutorial/app/Invitations" region="join" lang="tsx" />

3. **Follow the handshake.** Both sides read their flow's latest event with `useInvitationFlow`, which follows the
   `Invitation.events` stream. The host's side looks like this:

   <Snippet file="halo-tutorial/app/Invitations" region="events" lang="tsx" />

   `event` is `undefined` until the flow emits for the first time. At `readyForAuthentication`, the host's
   `event.authCode` holds the authorization code, and the `Status` component shows it. The guest's event has none, so
   the `Guest` component asks for the code.

4. **Send the authorization code.** On the guest, **Send** calls `handleAuthenticate` with the digits Bob typed, and
   `Invitation.authenticate` sends them to the host.

   <Snippet file="halo-tutorial/app/Invitations" region="authenticate" lang="tsx" />

   A wrong code does not fail `handleAuthenticate`. The flow goes back to `readyForAuthentication` so Bob can try
   again, and after three wrong codes it ends in `error`.

</Steps>

## Try it

Alice has Book club, and Bob has nothing yet.

1. On Alice's device, press **Invite** and copy the code.
2. On Bob's, press **Join**, paste it and press **Join**.
3. Alice's device now shows an authorization code. Type it into Bob's and press **Send**.

Bob's dropdown now has Book club, and both devices list Alice and Bob under People. Rename one of them and watch the
other follow.
