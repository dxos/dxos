By the end of this page Alice has a recovery code, and with it gets her name, spaces and contacts back on a new laptop.

## Before you start

If every device is lost, the identity is lost with them, unless it has a recovery credential: a key kept outside every
device. A recovery code is one such key, written as twelve words. Making it adds the key to the identity's group as a
member, the same way a device is added, so the key can admit a new device later.

Recovery goes through EDGE. The new device asks EDGE for a challenge, signs it with the key derived from the words, and
EDGE checks the signature against the identity's recovery credentials before it admits the device. The new device is a
new member of the same identity, with the same DID, and syncs its spaces from EDGE and from anyone online.

HALO shows a recovery code once and keeps only its public half, and it will not revoke the last code you have: make the
new one first. A passkey works the same way; see [Passkey recovery](/docs/halo/guides/passkey-recovery/).

The functions go in a new file, `recovery.ts`.

<Steps>

1. **Make a recovery code.** `Identity.createRecoveryCredential` makes the key, adds it to the identity, and returns the
   words. **Make a recovery code** on the Recovery tab calls this.

   <Snippet file="halo-tutorial/recovery" region="create" />

2. **List your codes.** `Identity.credentials` is a stream of the identity's credentials. A recovery credential carries
   its kind, a label, the date it was made, a lookup key and whether it was revoked. The Recovery tab lists the ones still
   active.

   <Snippet file="halo-tutorial/recovery" region="list" />

3. **Revoke a code.** `Identity.revokeRecoveryCredential` takes the lookup key. Revoke a code you think someone has seen.

   <Snippet file="halo-tutorial/recovery" region="revoke" />

4. **Recover on a new device.** On a device with no identity, `Identity.recover` takes the words and gets the identity
   back. **Recover with a code** calls this.

   <Snippet file="halo-tutorial/recovery" region="recover" />

</Steps>

## Try it

Open **Recovery** on Alice's laptop and make a code. Make a second one, then revoke the first. Try revoking the last one
too, and HALO refuses.

## What you can do now

You can make and revoke recovery codes, and recover an identity on a new device. That is the whole contact book. From
here, [Core concepts](/docs/halo/concepts/identities-devices/) explains the model behind it, and the
[API](/docs/halo/api/identity/) pages cover the rest of `@dxos/halo`.
