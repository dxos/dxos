---
title: llms.txt
description: The ECHO site map for agents, in the llms.txt format.
---

[`/echo/llms.txt`](/echo/llms.txt) gives an agent the ECHO site map: each page with its summary and a link to its Markdown, in the [llms.txt](https://llmstxt.org/) format. Point an agent at it before asking it to write ECHO code.

[`/echo/llms-full.txt`](/echo/llms-full.txt) has every ECHO page in one file, for an agent that reads the whole site at once.

| File                                     | Contents                                   |
| ---------------------------------------- | ------------------------------------------ |
| [`/echo/llms.txt`](/echo/llms.txt)           | Each page's title, summary and Markdown link |
| [`/echo/llms-full.txt`](/echo/llms-full.txt) | The full text of every page                |
