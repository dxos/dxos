A relation is an object with two typed endpoints, a source and a target. In a relational database, you would link
two rows with a join table that has columns of its own.

Use a relation when the link has data of its own, such as a role or a date, or when you need to query it from either
end. A plain `Ref` field is enough when one object just points at another.

`Relation` mirrors [Obj](/docs/echo/api/obj/) for everything that is not about endpoints.

## Make a relation

Declare the type with `Type.makeRelation`, which fixes the endpoint types
<SpecCite item="org.dxos.echo#F-2.2" />. Then call `Relation.make`, and pass the endpoints under the reserved
`Relation.Source` and `Relation.Target` keys.

## Read the endpoints

`getSource` and `getTarget` return the endpoint objects with their types.

`getSourceURI` and `getTargetURI` return the endpoints' URIs without resolving them. Use them when you do not need
the objects.

## Query from either end

`targetOf` selects the relations that point at the current selection, and `sourceOf` selects the ones that start from
it. From those relations, `source()` or `target()` steps to the objects at the other end.

In this example, `jobsAtAcme` holds the `WorksAt` relations that point at Acme. `staff` adds `source()`, so it holds
the people at the other end.

## Update, subscribe and sort

`Relation.update` writes to a relation and `Relation.subscribe` watches it, as in `Obj`. `Relation.sort`,
`sortByLabel` and `sortByTypename` are comparators for `Array.sort`.

## Members at a glance

| Member                                     | Summary                                       |
| ------------------------------------------ | --------------------------------------------- |
| `make`                                     | Create a relation between two objects         |
| `Source` `Target`                          | Reserved keys for the endpoints               |
| `getSource` `getTarget`                    | The endpoint objects                          |
| `getSourceURI` `getTargetURI`              | The endpoint URIs, unresolved                 |
| `update` `subscribe` `getSnapshot`         | Write, watch and copy, as in `Obj`            |
| `sort` `sortByLabel` `sortByTypename`      | Comparators for `Array.sort`                  |
| `instanceOf` `isRelation`                  | Predicates                                    |

The full list is in the [API reference](/docs/additional-resources/api-reference/).
