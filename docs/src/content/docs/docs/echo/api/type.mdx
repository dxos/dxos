A type names a kind of entity and fixes its fields. You declare one at module scope as a class, and that class is both
the runtime schema and the TypeScript type of its instances. Every type carries a DXN with a typename and a version, so
two peers agree on what an object is without sharing code.

## Declare an object type

`makeObject` takes the DXN first, then the fields. The optional second argument pipes annotations onto the schema, here
the field that labels an object in lists.

<Snippet file="guide-type" region="object" />

The last segment of the typename must be camelCase. A typename such as `com.example.type.works-at` fails to compile.

## Declare a relation type

A relation type also names the types of its two endpoints. [Relation](/docs/echo/api/relation/) covers making
instances.

<Snippet file="works-at" region="relation" />

## Convert to and from JSON Schema

The `JsonSchema` module converts a type's schema to JSON Schema and back. `Type.makeObjectFromJsonSchema` builds a type
from JSON Schema, for a type that comes from a form, an agent or another system.

<Snippet file="guide-type" region="json-schema" />

## Change fields at runtime

A type stored in a space with `db.addType` can gain and lose fields after it exists; the change replicates like any
write. The functions throw for a type that is not stored. Objects already made from the type keep their data. Use a new
version and a [migration](/docs/echo/api/migration/) instead when old objects need converting.

<Snippet file="guide-type" region="fields" />

## Members at a glance

| Member                                          | Summary                                         |
| ----------------------------------------------- | ----------------------------------------------- |
| `makeObject`                                    | Declare an object type                          |
| `makeRelation`                                  | Declare a relation type with typed endpoints    |
| `makeObjectFromJsonSchema`                      | Build an object type from JSON Schema           |
| `addFields` `updateFields` `removeFields`       | Change the fields of a type at runtime          |
| `getTypename` `getVersion` `getURI` `getMeta`   | Read the identity and metadata of a type        |
| `getSchema`                                     | The Effect Schema of a type                     |
| `JsonSchema.toJsonSchema` `JsonSchema.toEffectSchema` | Convert to and from JSON Schema           |
| `isObject` `isRelation` `isType`                | Test what kind of type a value is               |

The full list is in the [API reference](/docs/additional-resources/api-reference/).
