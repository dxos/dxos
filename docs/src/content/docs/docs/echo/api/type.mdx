A type names a kind of entity and fixes its fields. You declare one at module scope as a class, and that class is both
the runtime schema and the TypeScript type of its instances.

Every type carries a DXN with a typename and a version. This means two peers agree on what an object is without
sharing code.

## Declare an object type

`makeObject` takes the DXN first, then the fields. The optional second argument pipes annotations onto the schema.

## Convert to and from JSON Schema

The `JsonSchema` module converts a type's schema to JSON Schema and back.

`Type.makeObjectFromJsonSchema` builds a type from JSON Schema. Use it when the type comes from a form, an agent or
another system.

**Example** (Converting a type to JSON Schema, and building one from it)

<Snippet file="guide-type" region="json-schema" />

In this example, `jsonSchema` is a JSON Schema document for `Organization`. `Note` goes the other way. It is a type
built at runtime from a typename, a version and a JSON Schema with one `title` field.

## Change fields at runtime

A type stored in a space with `db.addType` can gain and lose fields after it exists, and a field can get a new
declaration. The change replicates like any write.

The functions throw for a type that is not stored. Objects already made from the type keep their data. When old
objects need converting, use a new version and a [migration](/docs/echo/concepts/types/#versions-and-migrations)
instead.

**Example** (Adding a field to a stored type, changing it and removing it)

<Snippet file="guide-type" region="fields" />

In this example, `db.addType` stores `Note` first. `Type.addFields` then gives the stored type an optional `pinned`
field. `Type.updateFields` declares the field again, as a number, and `Type.removeFields` takes it away.

## Members at a glance

| Member                                          | Summary                                         |
| ----------------------------------------------- | ----------------------------------------------- |
| `makeObject`                                    | Declare an object type                          |
| `makeRelation`                                  | Declare a relation type with typed endpoints    |
| `makeObjectFromJsonSchema`                      | Build an object type from JSON Schema           |
| `addFields` `updateFields` `removeFields`       | Change the fields of a type at runtime          |
| `getTypename` `getVersion` `getURI` `getMeta`   | Read the identity and metadata of a type        |
| `getSchema`                                     | The Effect Schema of a type                     |
| `JsonSchema.toJsonSchema` `JsonSchema.toEffectSchema` | Convert to and from JSON Schema           |
| `isObject` `isRelation` `isType`                | Test what kind of type a value is               |

The full list is in the [API reference](/docs/additional-resources/api-reference/).
