A filter is a predicate that says which entities match. An entity is an object or a relation. You build a filter, then
pass it to `db.query` directly or through `Query.select`.

Every builder is O(1). It creates an AST node and matches nothing until the query runs.

## Match by type

`Filter.type` takes an ECHO type and an optional props shape, so field names and value types are checked. Use it when
you know the type.

`Filter.props` matches on shape alone. It does not look at the type. Use it when objects of several types share a
field.

`untyped` takes `{ name: string }` as a type argument, because with no ECHO type there is nothing else to check the
field against. It matches an organization named Ada as well as a person.

## Match by id, tag or key

These three filters match on what ECHO keeps about an entity, whatever its type.

- `Filter.id` matches the entities with the ids you pass. Use it when you already know which entities you want.
- `Filter.tag` matches the entities that carry a tag. It takes the tag's URI, which `Obj.getURI` returns.
- `Filter.key` matches the entities whose metadata carries a **registry key**, the dotted name of an entry in the
  [registry](/docs/echo/concepts/spaces/#the-hypergraph). Pass `version` with a semver range when you want only some
  versions. Without it, `key` matches any version.

**Example** (Matching by id, by tag and by key)

<Snippet file="filter" region="identity" />

`'^1.0.0'` is a semver range, so `fromEntry` matches versions from 1.0.0 up to, and not including, 2.0.0. `speaker`
goes through `db.add` before the filter is built, because a tag is an object and its URI names the stored one.

## Match by foreign key

`Filter.foreignKeys` matches the entities of a type that carry one of the foreign keys you pass. A **foreign key** is
the id an entity has in another system, kept in its metadata as a `source` and an `id`. Use this filter in a sync, to
find the object a record became before you write the record again.

## Compare a field

Comparators go in the props shape, on the field they test. A plain value there tests for equality.

- `Filter.eq` and `Filter.neq` test for a value, or for any other value.
- `gt`, `gte`, `lt` and `lte` test against one bound. `between` tests against two, and its upper bound is exclusive.
- `in` matches a field that equals one of several values.
- `contains` matches an array field that holds a value.

`Filter.type`, so the compiler checks each comparator against the type of its field.

## Match everything or nothing

`Filter.everything` matches every object, and `Filter.nothing` matches none. Use `Filter.nothing` when code has to
pass a filter and should get no results. `Filter.id` returns it when you pass no ids.

## Search text

`Filter.text` runs a full-text search for the words you pass. Use it for a search box.

`options.type` is `'full-text'` by default. `'vector'` is declared for search by embedding. However, no query executor
runs it yet, so a vector search matches nothing.

## Filter by time

`Filter.created` matches by creation time, and `Filter.updated` by update time. Each takes a range with an `after`
bound, a `before` bound or both.

Both bounds accept a number of milliseconds or a `Date`. If you set both, the filter is the AND of the two.

`recent` sets no `before` bound, so it matches everything updated from 1 November 2026 on.

## Filter by parent

`Filter.childOf` matches the children of one or more objects. By default, it also matches their children in turn.
Set `transitive` to false when you want the direct children only.

`childOf` takes objects or references, and it reads a reference's URI without loading the target.

## Filter changes

`Filter.changes` selects the changes to some objects, or to every object in the space, instead of the objects. Use it
when you show a history.

You can order the changes by `time`, or count them with an [aggregate](/docs/echo/api/query/#aggregate-results).

**Example** (Selecting the changes to one object)

<Snippet file="filter" region="changes" />

`history` is a query of `Change` records and not of events, so each of its 50 results has a `time` and an `actor`,
and no `title`.

## Filter a feed by cursor

`Filter.feedCursor` matches the items of a feed between two cursors. A cursor marks one item. You read it from the
item with `Feed.getCursor`, or with `Feed.getLocalCursor` in a walk.

Use this filter when a reader keeps its place and wants only what is new. It works only in a query whose `from`
names a feed.

## Members at a glance

| Member                                | Signature                               | Summary                               |
| ------------------------------------- | --------------------------------------- | ------------------------------------- |
| [`type`](#match-by-type)              | `(type, props?) => Filter<T>`           | Objects of a type, optionally by props |
| [`props`](#match-by-type)             | `(props) => Filter<T>`                  | Objects whose fields match            |
| [`id`](#match-by-id-tag-or-key)       | `(...ids) => Filter`                    | Entities with one of the ids          |
| [`tag`](#match-by-id-tag-or-key)      | `(tag) => Filter`                       | Entities that carry a tag             |
| [`key`](#match-by-id-tag-or-key)      | `(key, options?) => Filter`             | Entities made from a registry entry   |
| [`foreignKeys`](#match-by-foreign-key) | `(type, keys) => Filter<T>`            | Entities of a type that carry a foreign key |
| [`eq` `neq`](#compare-a-field)        | `(value) => Filter<T>`                  | Equal, not equal                      |
| [`gt` `gte` `lt` `lte`](#compare-a-field) | `(value) => Filter<T>`              | Ordered comparison                    |
| [`between`](#compare-a-field)         | `(from, to) => Filter<T>`               | From inclusive, to exclusive          |
| [`contains`](#compare-a-field)        | `(value) => Filter<readonly T[]>`       | Array field holds the value           |
| [`in`](#compare-a-field)              | `(...values) => Filter<T>`              | Field equals one of the values        |
| [`and` `or` `not`](#combine-filters)  | `(...filters) => Filter<T>`             | Boolean combinators                   |
| [`everything` `nothing`](#match-everything-or-nothing) | `() => Filter`         | Every object, or none                 |
| [`text`](#search-text)                | `(text, options?) => Filter`            | Full-text search                      |
| [`created` `updated`](#filter-by-time) | `({ after?, before? }) => Filter`      | Timestamp range                       |
| [`childOf`](#filter-by-parent)        | `(parents, options?) => Filter`         | Children of an object                 |
| `hasParent`                           | `(value?) => Filter`                    | Objects that have a parent, or with `false` the ones that have none |
| [`changes`](#filter-changes)          | `(targets?) => Filter`                  | Changes instead of objects            |
| [`feedCursor`](#filter-a-feed-by-cursor) | `(range?) => Filter`                 | Feed items between two cursors        |
| `entity`                              | `(entity) => Filter<T>`                 | The entity you hold, by its id        |
| `mnemonic`                            | `(mnemonic) => Filter`                  | The object with a mnemonic            |
| `annotation`                          | `(annotation, value?) => Filter`        | Entities that carry an annotation set with `Annotation.set` |

The full list is in the [API reference](/docs/echo/resources/api-reference/).
