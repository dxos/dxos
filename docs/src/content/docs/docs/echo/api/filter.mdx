```ts
import { Filter } from '@dxos/echo';
```

Build a predicate, then pass it to `db.query` directly or through `Query.select`. Every builder is O(1): it creates an AST
node and matches nothing until the query runs.

| Member                                | Signature                               | Summary                               |
| ------------------------------------- | --------------------------------------- | ------------------------------------- |
| [`type`](#match-by-type)              | `(type, props?) => Filter<T>`           | Objects of a type, optionally by props |
| [`props`](#match-by-type)             | `(props) => Filter<T>`                  | Objects whose fields match            |
| [`eq` `neq`](#compare-a-field)        | `(value) => Filter<T>`                  | Equal, not equal                      |
| [`gt` `gte` `lt` `lte`](#compare-a-field) | `(value) => Filter<T>`              | Ordered comparison                    |
| [`between`](#compare-a-field)         | `(from, to) => Filter<T>`               | From inclusive, to exclusive          |
| [`contains`](#compare-a-field)        | `(value) => Filter<readonly T[]>`       | Array field holds the value           |
| [`in`](#compare-a-field)              | `(...values) => Filter<T>`              | Field equals one of the values        |
| [`and` `or` `not`](#combine-filters)  | `(...filters) => Filter<T>`             | Boolean combinators                   |
| [`text`](#search-text)                | `(text, options?) => Filter`            | Full-text or vector search            |
| [`created` `updated`](#filter-by-time) | `({ after?, before? }) => Filter`      | Timestamp range                       |
| [`childOf`](#filter-by-parent)        | `(parents, options?) => Filter`         | Children of an object                 |
| [`changes`](#filter-changes)          | `(targets?) => Filter`                  | Changes instead of objects            |

## Match by type

`type` takes an ECHO type and an optional props shape, so field names and value types are checked. `props` matches on shape alone.

## Filter by parent

`childOf` matches the children of one or more objects, and their children in turn unless `transitive` is false. It takes
objects or references, and reads a reference's URI without loading the target.

<Snippet file="filter" region="parent" />

## Filter changes

`changes` selects the changes to some objects, or to every object in the space, instead of the objects. Order them by
`time`, or count them with an [aggregate](/docs/echo/api/query/#aggregate-results).
