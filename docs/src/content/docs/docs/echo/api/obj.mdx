`Obj` makes objects and reads and writes them.

Its functions take the object as the first argument, and they work whether or not the object is in a database yet. A
getter that needs the database returns `undefined` outside one instead of throwing.
<SpecCite item="org.dxos.echo#F-3.3" />

## Make an object

`Obj.make` checks the props against the type and gives the object an id. Managed fields, the ones ECHO keeps beside
the type's own, go in the same props. <SpecCite item="org.dxos.echo#F-3.1" />

**Example** (Making a person with a foreign key)

<Snippet file="guide-obj" region="make" />

`ada` exists only in memory until `db.add` stores it. The key under `Obj.Meta` is a **foreign key**, the id this
person has in `crm.example.com`.

The props take three keys for managed fields:

- `id` sets the object's id. Without it, `Obj.make` makes a new one.
- `Obj.Meta` sets the metadata, such as foreign keys and tags.
- `Obj.Parent` sets the object's parent.

`Obj.make` also takes options as a third argument. `skipValidation` leaves out the check of the props against the
type. Use it only for props the compiler has already checked, when the check costs too much for large objects. With
it, `Obj.make` does not reject invalid props.

## Read and update an object

You read a field like any property. Writes go inside `Obj.update`, and a write outside it throws. All the writes in
one callback reach subscribers as one change.

A live object always shows the latest state. `Obj.getSnapshot` returns a snapshot, an immutable copy that later updates
do not touch. Use it when you want to keep a before-and-after, or when you hand data to code that must not write it.

## Meta, tags, labels and parents

**Metadata** is the data ECHO keeps about an object and not in its fields: its foreign keys and its tags.

- `Obj.getMeta` returns all of it. Use it when you need the whole record, such as the list of tags.
- `Obj.getKeys` returns the foreign keys from one source. Use it in a sync, to find the id an object has in the other
  system.
- `Obj.addTag` and `Obj.removeTag` attach and detach a tag. Both run inside `Obj.update`.

A **tag** is an object of its own, of the `Tag` type. You make one with `Tag.make` and store it with `db.add`
before you attach it.

**Example** (Reading a foreign key and adding a tag)

<Snippet file="guide-obj" region="meta" />

A label is the text that lists and pickers show for an object.

- `Obj.getLabel` reads the field that the type's `LabelAnnotation` names, or `name` when the type names none.
- `Obj.setLabel` writes that field. It runs inside `Obj.update`.

[Annotation](/docs/echo/api/annotation/#read-annotations) reads a label and a description in its sample.

A parent is the object that another object belongs to. `Obj.setParent` names the parent of a child, and
`Obj.getParent` reads it. The parent must hold a reference to the child, and removing the parent removes the child.

## Read the history

Each change to an object is a `Change`. It holds the device that made the change, the time, and the **heads** of the
document after it, which are the ids that name that version of the document.

- `Obj.getChanges` lists the changes, for the whole object or for one field. For one field, each change carries the
  value before and after.
- `Obj.getVersion` reads the object at a change's heads. Use it when you need the object as it was, without touching
  the live object.

## Clone and serialize

`Obj.clone` returns a new object with the same type and fields, and an id of its own. Use it when you want to
duplicate a record. It copies references as they are, so the clone points at the same targets. Pass `deep` when you
want the referenced objects cloned too.

`Obj.toJSON` and `Obj.fromJSON` round-trip an object's id, type, metadata and references. Use them when an object has
to leave ECHO, for example in an export. <SpecCite item="org.dxos.echo#F-3.4" />

## Members at a glance

| Member                                      | Summary                                              |
| ------------------------------------------- | ---------------------------------------------------- |
| `make`                                      | Create an object of a type                           |
| `update`                                    | Write to an object. One notification per call        |
| `getSnapshot`                               | An immutable copy of the current state               |
| `subscribe`                                 | Run a callback after each change                     |
| `getMeta` `getKeys` `deleteKeys`            | Read and change metadata and foreign keys            |
| `addTag` `removeTag`                        | Tag an object                                        |
| `getLabel` `setLabel`                       | The label lists and pickers show                     |
| `getParent` `setParent`                     | Parent and child ownership                           |
| `getChanges` `getVersion` `getBranch`       | History, past versions and the current branch        |
| `instanceOf` `isObject` `isDeleted`         | Predicates                                           |
| `clone` `toJSON` `fromJSON`                 | Copy and serialize                                   |

Functions shared by objects and relations, such as `getURI` and `getTypename`, are also in the `Entity` namespace.
The full list is in the [API reference](/docs/echo/resources/api-reference/).
