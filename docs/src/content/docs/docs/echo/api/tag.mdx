A tag is an object with a label and an optional hue. An object carries tags in its metadata, so tagging an object does not
change its fields, and one tag can label objects of any type.

## Tag an object

`Tag.findOrCreate` returns the space's tag with a label, or makes one. `Obj.addTag` adds it to an object inside
`Obj.update`.

<Snippet file="guide-tag" region="add" />

## Query by tag

`Filter.tag` takes the tag's URI.

<Snippet file="guide-tag" region="query" />

## Remove a tag

`Obj.removeTag` takes the tag off one object. Deleting the tag object does not delete the objects that carry it.

<Snippet file="guide-tag" region="remove" />

## Members at a glance

| Member | Summary |
| --- | --- |
| `Tag` | The tag object type |
| `make` `findOrCreate` | Make a tag, or reuse one with the same label |
| `findTagByLabel` `createTagList` `sortTags` | Work with a set of tags |
| `Obj.addTag` `Obj.removeTag` | Tag an object, or untag it |
| `Filter.tag` | Query by tag |

The full list is in the [API reference](/docs/additional-resources/api-reference/).
