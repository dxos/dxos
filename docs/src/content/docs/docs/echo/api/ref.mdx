A reference is a field that points at another entity. It stores the target's DXN, not a copy, and it resolves the
target only when you ask. <SpecCite item="org.dxos.echo#F-4.1" />

See [References and DXNs](/docs/echo/concepts/references/) for the model. This page is the API.

## Make a reference

You can make a reference in three ways:

- `Ref.make` takes an object you already hold.
- `db.makeRef` takes a URI and returns a reference bound to the database, so it can load its target. Use it when you
  have a URI and no object.
- `Ref.fromURI` also takes a URI. However, its reference has nothing to load from until a database binds it.

## Resolve a reference

In a relational database, a foreign key gives you an id, and you run another query to read the row. With a
reference, you ask the reference for its target:

- `peek` returns the target if it is already in memory, and never starts a load. Use it where the code cannot wait.
- `load` waits for the target, reading it from disk or the network, and throws if it cannot be found.
- `tryLoad` does the same, but returns `undefined` instead of throwing. Use it when a missing target is not an error.
- `Ref.loadAll` loads an array of references at once.

**Example** (Peeking at, loading and batch-loading references)

<Snippet file="guide-ref" region="resolve" />

In this example, `loaded` is the organization or `undefined`, and it never waits. `employer` waits for the same

Avoid `ref.target`. It is deprecated because reading it starts a load as a side effect and can throw.

## Compare references

Each read of a reference field returns a new wrapper, so `===` never matches.

- Use `Ref.equals` when you compare two references.
- Use `Ref.hasEntityId` when you test a reference against a target id.

## Members at a glance

| Member                    | Summary                                                   |
| ------------------------- | --------------------------------------------------------- |
| `Ref(Type)`               | Schema of a reference field                               |
| `Array(Type)`             | Schema of an array of references                          |
| `make`                    | A reference to an object you hold                         |
| `fromURI`                 | An unbound reference from a URI                           |
| `loadAll`                 | Load many targets, skipping missing and deleted ones      |
| `equals` `hasEntityId`    | Compare references                                        |
| `isRef`                   | Predicate                                                 |
| `ref.peek()` `ref.load()` `ref.tryLoad()` | Read the target in memory, or load it     |
