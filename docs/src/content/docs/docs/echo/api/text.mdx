`Text` edits a string field as a sequence of characters. Use it when more than one person can type in the same field.

- If you assign a string, you replace the field, so of two concurrent assignments one wins.
- If you edit with `Text`, you insert and delete characters, so two people typing in the same field both keep their
  work.

See [Changes and branches](/docs/echo/concepts/changes/) for what merges and how.

## Edit text

You can edit any string field this way. It needs no special declaration. Call the functions inside `Obj.update`.

- `splice` removes and inserts characters at an index, like `Array.prototype.splice`.
- `update` replaces the whole value, but writes only the characters that differ. Use it when you have the new value
  and not the edit that made it.
- `apply` runs find-and-replace edits. It throws `TextEditNotFoundError` when a text to replace is missing.

## Text in an input

Take an input bound to an ECHO string, such as a `<textarea>` whose `value` is the field. When a peer's edit
arrives, React sets the whole value again, and the input loses its caret.

To keep the caret, save the selection before the remote change renders. Then move it by the number of characters the
change inserted or removed before it.

Write each local keystroke with `Text.update`, so it merges with what the peer typed.

## Members at a glance

| Member | Summary |
| --- | --- |
| `splice` | Remove and insert characters at an index |
| `update` | Replace the value with a minimal diff |
| `apply` | Find and replace |
