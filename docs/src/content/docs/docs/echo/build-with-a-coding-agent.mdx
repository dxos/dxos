## What the agent reads

The prompt has the agent read `/echo/llms-full.txt` first. It holds every ECHO page as Markdown, code samples
included, so the agent has the whole section in one fetch. The agent then sets the project up from the learning path's
package.json and Vite config, which pin each `@dxos` package to a build of main until the next npm release. [llms.txt](/docs/echo/resources/llms-txt/) lists the other files for agents.

## While it works

The agent sets up the project, writes the app and tells you how to run it. Run it when it says so and try what you
asked for. To try a shared app, open it in a second browser or a private window, so the second copy has an identity of
its own, and join with the code the first one gives you.

To build the learning path's app yourself instead, start with [The ECHO object](/docs/echo/learn/the-echo-object/).
