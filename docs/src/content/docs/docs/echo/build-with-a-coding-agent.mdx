## What the agent reads

The prompt has the agent read `/echo/llms-full.txt` first. It holds every ECHO page as Markdown, code samples
included, so the agent has the whole section in one fetch. [llms.txt](/docs/echo/resources/llms-txt/) lists the other files for agents.

## While it works

The agent stops after each page of the learning path to show you what changed. Run the app when it says how, and check
that it does what that page describes before you let it go on.

At the end you have the app the learning path builds: organizations, the people who work at them and the events they
attend, which a second peer can join and edit.

To build it yourself instead, start with [The ECHO object](/docs/echo/learn/the-echo-object/).
