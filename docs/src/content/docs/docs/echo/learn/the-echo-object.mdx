In the learning path we build one app: a contact book of organizations, the people who work at them, and the events
they attend. This page explains what the app is made of, and shows it finished.

## What an object is

Everything the app stores is an ECHO object. An object has three parts:

- **An id.** Every peer that holds the object knows it by the same id.
- **A type.** The type names a schema, which says what fields the object has. The compiler checks the fields, and so
  does ECHO when it stores them.
- **Fields.** You read them like the fields of a plain object. A field can hold a reference to another object, which
  is how a person points at the organization they work for.

In a client-server app, the record you hold is a copy that you fetched, and you send each change back in a request.
In ECHO, objects live in a space's database, on the device. Reading one never waits on the network.

A change is written locally first and then reaches the other peers in the space. When two peers change the same
object, ECHO merges their changes rather than keeping only one.

An object is also **live**. Your code can subscribe to it, or to a query, and run whenever it changes, wherever the
change came from. The app redraws itself this way.

[Objects and relations](/docs/echo/concepts/objects-relations/) describes the model in full.

## The finished app

Here the finished app runs on two devices side by side. Pick a type, open a record, and edit it in the form. Then
invite Bob from Alice's toolbar and join from his, and both devices show the same records.

On each page of the learning path, we build one piece of the app:

| Page | File | What it adds |
| --- | --- | --- |
| [Installation](/docs/echo/learn/installation/) | `App.tsx` | A client on the network, an identity and the app's space |
| [Defining types](/docs/echo/learn/defining-types/) | `schema.ts`, `seed.ts`, `Contacts.tsx` | Organization, Person and Event, and the first records |
| [Querying](/docs/echo/learn/querying/) | `Contacts.tsx`, `RecordForm.tsx` | Sorted lists, search, a live count and the people at an organization |
| [Mutating objects](/docs/echo/learn/mutating-objects/) | `RecordForm.tsx`, `Contacts.tsx`, `RecordGraph.tsx` | Adding, editing and removing records |
| [Sharing a space](/docs/echo/learn/sharing/) | `Share.tsx` | Invite and Join in the toolbar, so a second device can share the space |

The app is a React app, and each page quotes its ECHO code from the component that runs it. The pages explain the
ECHO calls in each sample. The [React guide](/docs/echo/guides/react/) explains the hooks and components around them.
