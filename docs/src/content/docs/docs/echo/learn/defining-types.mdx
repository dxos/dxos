By the end of this page the app will have its three types: organizations, the people who work at them, and the events
they attend.

## Background

In TypeScript, an interface tells the compiler what an object looks like, and then it is gone when the app runs. An
ECHO type is a schema with a name, and it is still there at run time. ECHO uses the schema three ways:

- The compiler uses it to check the fields of every object you create.
- ECHO uses it to check what it stores, and to send the type to peers that have not seen it.
- Your code can read it at run time. We build the app's forms, table and graph from the schemas, so we write none of
  them per type.

The schema is an [Effect Schema](https://effect.website/docs/schema/introduction/). The name is a DXN, which is a
reverse-domain name and a version, such as `com.example.type.person` at `0.1.0`. Use a domain you control, because
the name is global.

A field can hold a reference to another object, with `Ref.Ref(Type)`. A reference stores the target's URI, which is
its address, and not a copy. Every object that points at an organization sees the organization's latest name.

## Try it

The form beside the list is built from the selected type's schema. A website gets a URL field, an employer gets a
picker of organizations, and an event's attendees get a list of people. Choose a type to see its form, or a record to
see its values. Editing comes in [Mutating objects](/docs/echo/learn/mutating-objects/).

## What you can do now

You can declare object types with references between them, give a type an icon and a label, and create objects that
the compiler checks against their schema.
