By the end of this page the app will have its three types: organizations, the people who work at them, and the events they attend.

## Before you start

A type is a schema with a name. ECHO uses the schema three ways:

- The compiler uses it to check the fields of every object you create.
- ECHO uses it to check what it stores, and to send the type to peers that have not seen it.
- Code can read it at run time. The app's forms, table and graph are built from the schemas rather than written per type.

The schema is an [Effect Schema](https://effect.website/docs/schema/introduction/). The name is a DXN: a reverse-domain name and a version, such as `com.example.type.person` at `0.1.0`. Use a domain you control, since the name is global.

A field can hold a reference to another object, with `Ref.Ref(Type)`. A reference stores the target's identity, not a copy, so the graph stays consistent when the target changes.

## Try it

The form beside the list is built from the selected type's schema: a URL field for a website, a picker of organizations for an employer, and a list of people for an event's attendees. Choose a type to see its form, or a record to see its values. Editing comes in [Mutating objects](/docs/echo/learn/mutating-objects/).

## What you can do now

You can declare object types with references between them, give a type an icon and a label, and create objects that the compiler checks against their schema.
