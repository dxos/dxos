By the end of this page the app will add, edit and remove records, and you will watch a record change.

## Before you start

An object you make with `Obj.make` exists only in memory until you add it to a database. `db.add` starts tracking it: from then on the database stores every change and sends it to the space's other peers.

A tracked object is read like any other, but it is changed only inside `Obj.update`. The callback gets a mutable view of the object. Each update is one change, which peers apply whole, and which notifies subscribers once.

Writes are local. `db.add` and `Obj.update` return once the change is in the local database, and replication runs after. Two peers that change the same object concurrently both keep their edits: ECHO merges them field by field.

## Try it

Select a record and change it in the form, or press **New** to add one of the chosen type. The **×** on a row removes it. A person's employer is a picker of the organizations in the space.
