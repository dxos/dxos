By the end of this page the app will add, edit and remove records, and you will watch a record change.

## Background

An object you make with `Obj.make` exists only in memory until you add it to a database. `db.add` starts tracking it: from then on the database stores every change and sends it to the space's other peers.

A tracked object is read like any other, but it is changed only inside `Obj.update`. The callback gets a mutable view of the object. Each update is one change, which peers apply whole, and which notifies subscribers once.

Writes are local. `db.add` and `Obj.update` return once the change is in the local database, and replication runs after. Two peers that change the same object concurrently both keep their edits: ECHO merges them field by field.

Each change goes in the component that makes it: adding and editing in `RecordForm.tsx`, removing in `Contacts.tsx`, and watching in `RecordGraph.tsx`.

4. **Remove a record.** The **×** on a row calls this.

   <Snippet file="tutorial/app/Contacts" region="remove" lang="tsx" />

   <Aside type="note">
     ECHO does not delete a removed object at once. It marks the object as removed and keeps it in the change history
     until the next [epoch](/docs/additional-resources/glossary#epoch), so a peer that wrote while offline can still
     reconcile its changes when it reconnects.
   </Aside>

## Try it

Select a record and change a field: the form writes each change inside `Obj.update` as you type, and the list follows. Press **New** to add a record of the chosen type, and the **×** on a row removes it. The [React guide](/docs/echo/guides/react/) shows the form.
