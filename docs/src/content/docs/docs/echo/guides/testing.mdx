By the end of this guide you will have a test that runs against an in-memory database, and a test that replicates
between two peers.

A test of code that uses ECHO needs a database, and a test of sync needs more than one peer. `EchoTestBuilder` makes
both in memory, without an identity or a server, so tests run fast in Node.

## Make a database

`createDatabase` makes a peer with its own storage and opens a database on it. Pass the types the test uses.
`await using` closes the builder, and every peer it made, when the test ends.

## Replicate between peers

Each peer from `createPeer` has its own storage, like a separate device. A `TestReplicationNetwork` from
`@dxos/echo-host/testing` connects them in memory. Each peer joins the network by passing one of its replicators to
`host.addReplicator`.

One peer creates the space, and the other opens it from the space's root URL, the address of the space's root
document. `waitUntilHeadsReplicated` waits until one peer has all the changes another has made.

`getDocumentHeads` returns the heads of `db1`, which are the ids of the latest changes in each of its documents.
`db2` has caught up once it holds those changes, and the last line waits for exactly that.

Use two peers when you test what happens when both write. Make the writes on each peer, wait for each to have the
other's changes, then check that both show the same result.
