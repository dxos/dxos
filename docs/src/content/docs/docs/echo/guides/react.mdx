By the end of this page you will know how the tutorial app's components get their data, and why they re-render when any peer changes it.

## Before you start

The [learning path](/docs/echo/learn/the-echo-object/) builds the app's ECHO code in plain TypeScript: its types, its add and update functions, and its queries. This guide covers the React layer on top, which `@dxos/react-client` connects to ECHO.

Two rules decide when a component re-renders:

- A hook subscribes the component to what it returns. `useQuery` re-renders when the query's results change, and `useObject` when the object changes.
- Reading a field of an ECHO object during render subscribes to nothing. A component that reads `person.name` straight off the object does not re-render when the name changes.

<Steps>

1. **Install the React client.** `@dxos/react-client` wraps `@dxos/client` in a provider and hooks. Configure the bundler as in [Installation](/docs/echo/learn/installation/).

   <Tabs>
     <TabItem label="pnpm">
       ```bash
       pnpm add @dxos/react-client
       ```
     </TabItem>
     <TabItem label="npm">
       ```bash
       npm install --save @dxos/react-client
       ```
     </TabItem>
     <TabItem label="yarn">
       ```bash
       yarn add @dxos/react-client
       ```
     </TabItem>
   </Tabs>

2. **Provide the client.** `ClientProvider` gives the hooks below it a client. The app opens its client and space with `openContacts` from [Installation](/docs/echo/learn/installation/), and renders one provider per peer.

   <Snippet file="tutorial/app/PeerApp" region="provider" lang="tsx" />

3. **Query the space.** `useQuery` takes a database and a query, here the app's queries from [Querying](/docs/echo/learn/querying/). It returns the current results and re-renders the component when they change.

   <Snippet file="tutorial/app/Contacts" region="query" lang="tsx" />

   A query returns the same live object for an id every time, so a renamed record leaves the results array as it was. The app's list reads its labels with `useLabels`, which re-renders the list when a label changes.

4. **Show a record.** `useObject` returns a snapshot of the object and re-renders the component when the object changes. The form's title reads the record's name through it.

   <Snippet file="tutorial/app/RecordForm" region="title" lang="tsx" />

   <Aside type="caution">
     Read fields through the snapshot from `useObject`. A field read straight off the ECHO object shows its value at
     render time, and the component does not re-render when the field changes.
   </Aside>

5. **Edit a record.** `ObjectForm` from `@dxos/react-ui-form` builds its fields from the record's type and writes each change back inside `Obj.update`. A reference field lists the records of the type it points at.

   ```tsx
   <ObjectForm type={Person} object={person} showTags={false} />
   ```

6. **Create a record.** For a new record, `Form.Root` takes the type's schema and hands its values to `onSave`, which adds the record as in [Mutating objects](/docs/echo/learn/mutating-objects/).

   <Snippet file="tutorial/app/RecordForm" region="create" lang="tsx" />

</Steps>
