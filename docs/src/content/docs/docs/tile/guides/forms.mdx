`@dxos/react-ui-form` builds a form from an Effect schema. Each property becomes a field of the right kind, its
`title` annotation becomes the field's label, and the schema's checks become the form's validation. Change the schema
and the form follows. You do not write a field by hand.

```sh
npm install @dxos/react-ui-form
```

Register the package's strings with the theme provider, beside react-ui's:

```tsx
import { translations as formTranslations } from '@dxos/react-ui-form/translations';

<Theme.Provider tx={Theme.defaultTx} resourceExtensions={[...translations, ...formTranslations]}>
```

## Render the form

`Form.Root` takes the schema and the starting values. `Form.Fields` renders a field for each property, and
`Form.Actions` adds Save and Cancel. Save stays disabled until the values pass the schema's checks, then calls `onSave`
with them:

## Edit an ECHO object

For an object in a database, use `ObjectForm`. It takes the type and the object, and writes each change to the object
as the user makes it, so it needs no Save button. A property that refers to another object gets a picker of the
objects of that type. The types from ECHO's [Defining types](/docs/echo/learn/defining-types/) page work as they are:
