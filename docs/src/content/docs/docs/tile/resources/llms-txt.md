This page lists the two files that hold TILE's docs for a coding agent. Point your agent at them before you ask it
to work with TILE. They follow the [llms.txt](https://llmstxt.org/) format and cover every page of this section.

| File                                         | Contents                                                   |
| -------------------------------------------- | ---------------------------------------------------------- |
| [`/tile/llms.txt`](/tile/llms.txt)           | Each TILE page with its summary and a link to its Markdown |
| [`/tile/llms-full.txt`](/tile/llms-full.txt) | Every TILE page in one file                                |

You can also read any page as Markdown, at its URL with `.md` in place of the trailing slash.
