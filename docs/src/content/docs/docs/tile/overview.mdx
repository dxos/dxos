TILE is a design system for React apps. It gives you accessible, themed UI components in `@dxos/react-ui`, and in
`@dxos/ui-theme` the tokens and build plugin behind them. A **token** is a named color or size that the components
read in place of a fixed value. TILE needs neither [ECHO](/docs/echo/overview/), DXOS's database, nor
[PLEX](/docs/plex/overview/), its plugin framework, so you can use it in any React app.

Each demo below is a TILE component package running in this page, on sample data and with no database. You can drag
the cards, edit the cells and move the boxes. The demos follow the page's light or dark mode, and each card's header
opens the component's API page.

## Core and component packages

TILE comes as a core and the component packages built on it:

| Package                               | What it holds                                                                                       |
| ------------------------------------- | --------------------------------------------------------------------------------------------------- |
| `@dxos/react-ui`                      | The components, such as buttons, inputs, overlays, menus, layout, status and icons, and the theme provider |
| `@dxos/ui-theme`                      | The color and size tokens, the cascade layers, and the Vite plugin that generates the styles        |
| The other `@dxos/react-ui-*` packages | Lists, forms, menus, editors, tables and more, built on the core                                    |

The API section documents the core first. Each component package then has a group of its own, with one page per
component, such as [Board](/docs/tile/api/react-ui-mosaic/board/) in `@dxos/react-ui-mosaic`.

[Composer](/composer), DXOS's local-first workspace, and its plugins draw their UI with TILE.
[TILE in a PLEX plugin](/docs/tile/guides/tile-in-a-plex-plugin/) says what changes when your components run inside
a plugin.
