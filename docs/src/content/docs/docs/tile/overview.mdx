TILE is the DXOS design system: themed UI components, and the tokens and build plugin behind them. Composer and every
plugin draw their UI with it. Its core is `@dxos/react-ui`, which needs `@dxos/ui-theme` for its styles. It does not need
ECHO or PLEX, so it works in any React app.

The buttons below are the real components, rendered in this page. They follow the page's light or dark theme.

## Core and component packages

| Package                               | What it holds                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------- |
| `@dxos/react-ui`                      | The components: buttons, inputs, overlays, menus, layout, status, icons, and the theme provider |
| `@dxos/ui-theme`                      | The color and size tokens, the cascade layers, and the Vite plugin that generates the styles |
| The other `@dxos/react-ui-*` packages | Lists, forms, editors, tables and the plugin shell, built on the core                       |

These pages document the core. The other packages are listed in [Component packages](/docs/tile/resources/component-packages/).
