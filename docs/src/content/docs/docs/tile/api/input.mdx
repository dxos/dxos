`Input` holds the controls. `Field` gives a control its label, help text and error. `Select` picks one value from a
list.

## `Input`

| Part              | What it is                                                                     |
| ----------------- | ------------------------------------------------------------------------------ |
| `Input.Root`      | A text input. Takes the props of an `<input>`                                  |
| `Input.Textarea`  | Multi-line text                                                                |
| `Input.Number`    | A number, with steppers                                                        |
| `Input.Password`  | A password, with a button to show it                                           |
| `Input.Pin`       | A code of several single-character boxes                                       |
| `Input.Date`      | A date, a time, or both                                                        |
| `Input.Checkbox`  | A checkbox. `label` for its visible label                                      |
| `Input.Switch`    | An on/off switch. `label`, and `indeterminate` for a mixed state               |
| `Input.Slider`    | A value on a range                                                             |
| `Input.Frame`     | The frame a control sits in, for building a control of your own                |

`Input.Root` also takes:

| Prop         | Type                  | Effect                                                                      |
| ------------ | --------------------- | --------------------------------------------------------------------------- |
| `start`      | React node            | Content before the text, such as an icon or a currency                      |
| `end`        | React node            | Content after the text, such as a unit or an icon button                    |
| `copyable`   | boolean               | A button that copies the value; replaces `end`                              |
| `variant`    | `'default' \| 'subdued' \| 'mono'` | `subdued` drops the well; `mono` is for keys and ids           |
| `noAutoFill` | boolean               | Ask password managers not to offer to fill it, such as for a search box     |

Inside a `Field.Root`, a control takes the field's id, label and description, so it needs no `aria-label`.

## `Field`

| Part                       | What it is                                         |
| -------------------------- | -------------------------------------------------- |
| `Field.Root`               | Holds one control and its texts                    |
| `Field.Header`             | A row above the control, for the label and extras  |
| `Field.Label`              | The label. `srOnly` hides it but keeps it for screen readers |
| `Field.RequiredIndicator`  | The mark for a required field                      |
| `Field.HelperText`         | A hint under the control                           |
| `Field.ErrorText`          | The error, shown when the field is invalid         |

`Field.Root` takes `validationValence` to color the field by status, `layout='row'` to put the label beside the control,
and Ark's `invalid`, `required`, `disabled` and `readOnly`.

## `Select`

`Select.Root` takes `items`, a list of `{ value, label, disabled?, icon? }`, and `value` with `onValueChange`, or
`defaultValue`. `Select.Trigger` shows the chosen label, or its `placeholder`. `Select.Content` holds one `Select.Item`
per item, each given its `item`.
