An accordion is a stack of items that open and close. Each item has a trigger row and a region it shows or hides. Any
number of items can be open at once unless `multiple` is false.

## Parts

| Part | What it is |
| --- | --- |
| `Accordion.Root` | The stack of items |
| `Accordion.Item` | One section. A `disabled` item keeps its place but does not open |
| `Accordion.ItemTrigger` | The row that opens and closes the item. It holds an optional icon, the label and a caret |
| `Accordion.ItemContent` | The region the item shows. Its height animates as it opens |
