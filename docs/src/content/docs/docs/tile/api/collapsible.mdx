A collapsible is one region that opens and closes. The trigger is a caret and a label. Without a label, the trigger
is only the caret. Use it that way in a list row.

## Parts

| Part | What it is |
| --- | --- |
| `Collapsible.Root` | Holds the open state |
| `Collapsible.Trigger` | The caret and label that open and close the region |
| `Collapsible.Content` | The region; its height animates as it opens |
