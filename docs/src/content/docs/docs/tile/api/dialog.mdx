A dialog is a modal window for a task the user finishes or cancels before going on. It opens above the page, in a
portal, and the page behind it is inert until it closes.

The parts are `Dialog.Root`, `Dialog.Trigger`, `Dialog.Content`, `Dialog.Header`, `Dialog.Title`,
`Dialog.Description`, `Dialog.Body`, `Dialog.Footer` and `Dialog.CloseTrigger`.

- Use `open` and `onOpenChange` on `Dialog.Root` to open the dialog from code.
- `Dialog.CloseTrigger` with no children is a close button. With `asChild`, it makes its child close the dialog.
- Use `size` on `Dialog.Content` to set the dialog's size, from `'xs'` to `'xl'`. Without it, the dialog takes the
  size set around its trigger, or `'md'`.
- `Dialog.Body` scrolls when the content is taller than the screen.
