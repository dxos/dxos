```ts
import * as Dialog from '@dxos/react-ui/Dialog';
```

A dialog opens above the page, in a portal, and the page behind it is inert until it closes.

The parts are `Root`, `Trigger`, `Content`, `Header`, `Title`, `Description`, `Body`, `Footer` and `CloseTrigger`.

- `Dialog.Root` takes `open` and `onOpenChange`. Use them to open the dialog from code.
- `Dialog.CloseTrigger` with no children is a close button. With `asChild`, it makes its child close the dialog.
- `Dialog.Content` takes `size`.
- `Body` scrolls when the content is taller than the screen.
