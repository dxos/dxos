A tour points at parts of the app, one step at a time. `Tour.useTour` creates the tour from its steps. Each step can
highlight its target, center as a dialog, and offer next, back and skip.

## Parts

| Part | What it is |
| --- | --- |
| `Tour.useTour` | A hook that creates the tour from its steps |
| `Tour.Root` | The root, which provides the tour to the parts |
| `Tour.Content` | The card for the current step |
| `Tour.Header` | The row that holds `Tour.Title` |
| `Tour.Title` | The step's title |
| `Tour.Description` | The step's description |
| `Tour.Control` | The row for progress and actions |
| `Tour.ProgressText` | The step's position, as "1 of 4" |
| `Tour.Actions` | A render prop over the step's actions |
| `Tour.ActionTrigger` | A button for one action: next, back, dismiss or skip |
| `Tour.CloseTrigger` | The button that ends the tour |
