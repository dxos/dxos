```ts

```

Parts: `Root`, `Trigger` and `Content`. `Tooltip.Trigger` also takes `content` and `side` as a shorthand, with no
`Content` part. `Tooltip.TextTooltip` shows a text's full value when it is cut off. An icon-only button shows its label
as a tooltip without any of these.
