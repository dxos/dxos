A tooltip is a short name or hint for a control, shown on hover or focus. The parts are `Tooltip.Root`,
`Tooltip.Trigger` and `Tooltip.Content`.

- Use `content` on `Tooltip.Trigger` as a shorthand. The trigger then needs no `Tooltip.Root` or `Tooltip.Content`,
  and `side` sets the side the tooltip opens on.
- `Tooltip.TextTooltip` shows a text's full value when the text is cut off.

An icon-only button shows its label as a tooltip without any of these.
