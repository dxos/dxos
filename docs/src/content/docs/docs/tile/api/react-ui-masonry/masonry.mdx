`Masonry` packs tiles of different heights into columns. It puts each tile in the shortest column, so the columns have
no gaps.

The number of columns follows the width the masonry has. When the items change, the tiles that stay move to their new
places, and the masonry measures only the new ones.

## Parts

| Part | What it is |
| --- | --- |
| `Masonry.Root` | The root, which takes the `Tile` that draws one item, and the column sizes |
| `Masonry.Content` | The scroll area for the tiles |
| `Masonry.Viewport` | The tiles. It takes the `items` and a `getId` for each |

## `Masonry.Root`

`Masonry.Root` takes these props:

| Prop | Type | Effect |
| --- | --- | --- |
| `Tile` | `ComponentType<{ data }>` | Draws one item |
| `minColumnWidth` | `number` | Sets the narrowest a column gets, in rem |
| `maxColumnWidth` | `number` | Sets the widest a column gets, in rem |
| `maxColumns` | `number` | Sets the most columns |
| `gap` | `number` | Sets the space between tiles, in rem |

## Lay out tiles

Build each tile from a `Card` from `@dxos/react-ui`, so the tiles match the rest of the app.
