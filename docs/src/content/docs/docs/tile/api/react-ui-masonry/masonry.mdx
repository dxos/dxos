`Masonry` packs tiles of different heights into columns, each tile in the shortest column, so the columns have no
gaps. The number of columns follows the width it has. When the items change, the tiles that stay move to their new
places, and the masonry measures only the new ones.

## Parts

| Part | What it is |
| --- | --- |
| `Masonry.Root` | Takes the `Tile` that draws one item, and the column sizes |
| `Masonry.Content` | Scrolls the tiles |
| `Masonry.Viewport` | Takes the `items` and a `getId` for each |

## `Masonry.Root`

| Prop | Type | Effect |
| --- | --- | --- |
| `Tile` | `ComponentType<{ data }>` | Draws one item |
| `minColumnWidth` | `number` | The narrowest a column gets, in rem |
| `maxColumnWidth` | `number` | The widest a column gets, in rem |
| `maxColumns` | `number` | At most this many columns |
| `gap` | `number` | The space between tiles, in rem |
