The preview and the field share one place, so switching between them moves nothing.

## Parts

| Part | What it is |
| --- | --- |
| `Editable.Root` | Holds the value and the editing state |
| `Editable.Preview` | The text, and what starts editing |
| `Editable.Input` | The field shown while editing, with a save button |
