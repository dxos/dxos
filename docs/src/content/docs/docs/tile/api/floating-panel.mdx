A floating panel is a window the user can drag, resize, minimize and maximize. The panel keeps its own position, size
and stage, which is `minimized`, `maximized` or `default`. Several open panels stack in the order they were last used.

## Parts

| Part | What it is |
| --- | --- |
| `FloatingPanel.Root` | The root, which holds the open state, position and size |
| `FloatingPanel.Trigger` | The control that opens the panel |
| `FloatingPanel.Content` | The window |
| `FloatingPanel.Header` | The title row |
| `FloatingPanel.DragTrigger` | The area the user drags the panel by |
| `FloatingPanel.Title` | The window's name |
| `FloatingPanel.Control` | The buttons at the end of the header |
| `FloatingPanel.StageTrigger` | The button that minimizes, maximizes or restores the panel |
| `FloatingPanel.CloseTrigger` | The button that closes the panel |
| `FloatingPanel.Body` | The area under the header. It clips, so its content scrolls itself |
