`Picker` is an input and the items under it. The arrow keys move the highlight from the input, and Enter commits the
highlighted item, so the user never leaves the keyboard. You filter the items from the input's value.

## Parts

| Part | What it is |
| --- | --- |
| `Picker.Root` | Tracks the highlight; `resetSelectionOnChange` moves it to the first item as the results change |
| `Picker.Input` | The filter input; `value` and `onValueChange` hold the query |
| `Picker.Item` | An item with a `value`; `onSelect` runs when the user commits it |
