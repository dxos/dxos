`Tree` reads its rows from a model and reports what the user does to them. The model keeps each row's open and
current state in an atom, so the tree needs a `RegistryProvider` from `@effect/atom-react` above it. Each part handles keyboard navigation and the current and selected states, and sets its own spacing, so put
it in a panel's body with no padding around it.

## Parts

| Part | What it is |
| --- | --- |
| `Tree.Root` | Takes the `model` and an `id`; reports `onOpenChange` and `onSelect` |
| `Tree.Label` | Names the tree |
| `Tree.Content` | Scrolls the rows; its child can render each row |
| `Tree.Item` | One row, or a group header |
| `Tree.ItemIndicator` | The caret that opens a branch |
| `Tree.ItemIcon` | The row's icon |
| `Tree.ItemText` | The row's label |
| `Tree.ItemCount` | A count badge |
| `Tree.ItemActions` | Controls at the row's end, shown on the row in play |
| `Tree.ItemGroup` | A section header |
| `Tree.ItemGroupLabel` | A section header's label |
| `Tree.Empty` | Stands in for the rows while there are none |
