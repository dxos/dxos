`Listbox` is a flat list. With `value` and `onValueChange` the user picks one row; without them the list is only
for display. Each part handles keyboard navigation and the current and selected states, and sets its own spacing, so put
it in a panel's body with no padding around it.

## Parts

| Part | What it is |
| --- | --- |
| `Listbox.Root` | Takes the options as `items`; `value`, `onValueChange` and `onDeselect` make it selectable |
| `Listbox.Label` | Names the list; `srOnly` keeps it for screen readers |
| `Listbox.Viewport` | Scrolls the list |
| `Listbox.Content` | The listbox element |
| `Listbox.Item` | A row for the option whose value is `id` |
| `Listbox.ItemIcon` | The row's icon |
| `Listbox.ItemText` | The option's label |
| `Listbox.ItemDescription` | The option's description |
| `Listbox.ItemIndicator` | A check on the selected row |
| `Listbox.ItemGroup` | A group of rows |
| `Listbox.ItemGroupLabel` | A group's heading |
| `Listbox.Empty` | Stands in for the rows while there are none |
