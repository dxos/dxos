`OrderedList` gives each row a drag handle. A drop, or a keyboard move from the handle, calls `onMove` with the old
and the new index, and you update your state. Each part handles keyboard navigation and the current and selected states, and sets its own spacing, so put
it in a panel's body with no padding around it.

## Parts

| Part | What it is |
| --- | --- |
| `OrderedList.Root` | Takes the `items`, `getId`, `getLabel` and `onMove`; its child is a function of the items |
| `OrderedList.Label` | Names the list |
| `OrderedList.Viewport` | Scrolls the list, and scrolls it during a drag near its edges |
| `OrderedList.Content` | The listbox element |
| `OrderedList.Item` | A row; `collapsible` folds a `Detail` under it |
| `OrderedList.DragHandle` | The grip the user drags, or moves with Alt and the arrow keys |
| `OrderedList.Detail` | A collapsible row's detail, at full width |
| `OrderedList.ItemIcon` | The row's icon |
| `OrderedList.ItemText` | The row's text |
| `OrderedList.ItemDescription` | The row's description |
| `OrderedList.Empty` | Stands in for the rows while there are none |
