`single` lets one item be on at a time; `multiple` lets any number be on. Arrow keys move between the items.

## Parts

| Part | What it is |
| --- | --- |
| `ToggleGroup.Root` | Holds which items are on |
| `ToggleGroup.Item` | One toggle |
