Enter moves into a group and Escape leaves it. See [Focus and keyboard](/docs/tile/concepts/focus-and-keyboard/).

## Parts

| Part | What it is |
| --- | --- |
| `Focus.Group` | One Tab stop over its children; arrow keys move between them |
| `Focus.Item` | A member the group moves between as one unit |
| `Focus.bindItem` | The props that make an element an item |
| `Focus.useFocus` | The group's state, for a member to report into |
