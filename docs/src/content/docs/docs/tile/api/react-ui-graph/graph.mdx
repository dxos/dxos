`Graph` draws the nodes and edges of a `GraphModel` from `@dxos/graph`. A **projector** decides where each node goes.

The force projector pulls linked nodes together and pushes the rest apart. Use it when the graph has no natural
order, such as people and the teams they belong to. The package has other projectors for trees, rings and layers.

`Graph` draws inside [`SVG.Root`](/docs/tile/api/react-ui-graph/svg/). Import the package's styles,
`@dxos/react-ui-graph/styles/graph.css`, once in your app.

## Props

| Prop | Type | Effect |
| --- | --- | --- |
| `model` | `GraphModel` | Sets the nodes and edges |
| `projector` | `GraphProjector` | Places the nodes. Make your own after `SVG.Root` mounts. A `GraphForceProjector` by default |
| `renderer` | `GraphRenderer` | Draws the layout. One made from the props below by default |
| `labels` | `{ text }` | Sets what to write beside each node |
| `attributes` | `{ node, edge }` | Sets classes and `data-` attributes for each node and each edge |
| `subgraphs` | `boolean` | Draws a hull around each group of more than two connected nodes |
| `renderNode` | `(group, node) => void` | Draws a node, in place of the default circle |
| `applyNode` | `(group, node) => void` | Runs for each node after its position changes |
| `highlightOnHover` | `boolean` | Colors a hovered node's edges and dims the rest |
| `edgeOpacity` | `number` | Sets the opacity of the edges |
| `drag` | `boolean` | Lets the user move a node |
| `arrows` | `boolean` | Ends edges in arrowheads |
| `onSelect` | `(node, event) => void` | The user clicked a node |
| `onInspect` | `(node \| null, event) => void` | The pointer entered a node, or left it |
| `onPointerMove` | `(point, event) => void` | The pointer moved over the graph. `point` is in the nodes' coordinates |
| `onPointerLeave` | `(event) => void` | The pointer left the graph |

## Draw a graph

You build the model first, then draw it:

- `addNode` takes an `id`, and optionally a `type` and any `data`.
- `addEdge` takes a `source` and a `target`.
- `SVG.Zoom` lets the user zoom and pan.
- `SVG.Graph` draws the model.

The projector needs the SVG context, so make it in an effect after `SVG.Root` mounts.
