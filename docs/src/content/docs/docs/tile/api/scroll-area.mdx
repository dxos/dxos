A scroll area is a scrolling region with a themed scrollbar. `ScrollArea.Root` holds the scrollbar, and
`ScrollArea.Viewport` holds the content.

- `orientation` on `ScrollArea.Root` is `'vertical'` by default.
- `width` is `'thin'` by default, or `'regular'`.

Use `asChild` on `Panel.Body` to put the body on a `ScrollArea.Root`. See [Panel](/docs/tile/api/panel/).
