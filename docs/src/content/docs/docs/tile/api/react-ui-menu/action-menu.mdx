`ActionMenu` draws a list of actions as a dropdown menu, with groups as submenus. Its child is the button that opens it. An action is a label, an icon and the function it runs. You build the list with `MenuBuilder` and
`useMenuBuilder`, and because the list is data, other code can add to it, which is how Composer plugins add buttons to
each other's toolbars. The actions live in an atom, so wrap your app in `RegistryProvider` from
`@effect/atom-react/RegistryContext`, and register the strings from `@dxos/react-ui-menu/translations`.

## Props

| Prop | Type | Effect |
| --- | --- | --- |
| `...menu` | `MenuActions` | The actions, from `useMenuBuilder` |
| `actions` | `MenuItem[] | () => MenuItem[]` | Items in place of the group's own |
| `group` | `MenuGroupContext` | The group whose items the menu shows |
| `open` | `boolean` | Controls whether the menu is open, with `onOpenChange` |
| `deferUntilOpen` | `boolean` | Builds the menu on the first click, for a menu on every row of a list |
| `children` | `ReactNode` | The trigger |
