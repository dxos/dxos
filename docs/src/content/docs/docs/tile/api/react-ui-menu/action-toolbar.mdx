`ActionToolbar` draws a list of actions as a toolbar. When the row is too narrow, it moves actions into an overflow
menu.

An **action** is a label, an icon and the function it runs. You build the list with `MenuBuilder` and
`useMenuBuilder`. Because the list is data, other code can add to it. This is how Composer plugins add buttons to each
other's toolbars.

The actions live in an atom.

Wrap your app in `RegistryProvider` from `@effect/atom-react`. This is best practice, because your app then controls
the registry that the toolbar reads. Without a provider, the toolbar reads the library's default registry.

Also register the strings from `@dxos/react-ui-menu/translations`.

## Props

| Prop | Type | Effect |
| --- | --- | --- |
| `...menu` | `MenuActions` | The actions, from `useMenuBuilder` |
| `attendableId` | `string` | The toolbar is dimmed while this surface lacks the user's attention |
| `alwaysActive` | `boolean` | Never dimmed |
| `customActions` | `Atom<ActionGraphProps>` | Actions another component adds to this toolbar |
| `bounds` | `HTMLElement \| null` | The box whose width the toolbar may fill; its own frame by default |

## Build a toolbar

`useMenuBuilder` takes a function that builds the actions, and the values that function depends on.

- Give an action `iconOnly` to show only its icon, with the label as its tooltip.
- Give it `placement: { zone: 'end' }` to put it at the far end of the row.

Pass `alwaysActive` when the toolbar does not belong to a surface that tracks the user's attention.

## Show state

A switch shows whether something is on. Pass the state as `checked`, and list it in the dependencies, so
`useMenuBuilder` rebuilds the actions when the state changes.

## In a plugin

In a Composer plugin, other plugins add actions to an object's node in [App Graph](/docs/plex/guides/app-graph/).
`graphActions` reads the ones marked for the toolbar and adds them to yours.

- Pass the surface's `attendableId`, so the toolbar is active while its surface has the user's attention.
- Pass `onAction` to run a graph action. `useActionRunner` from plugin-graph gives you one.
