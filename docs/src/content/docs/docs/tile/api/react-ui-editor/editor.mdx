`Editor` is the text editor Composer uses for documents, built on CodeMirror.

- The React parts draw the editor and its toolbar.
- The extensions from `@dxos/ui-editor` decide what the editor does: markdown, formatting, themes, and binding the
  text to an ECHO object.

## Parts

| Part | What it is |
| --- | --- |
| `Editor.Root` | The root, which holds the extensions and the editor's state. `viewMode` sets source, preview or read-only |
| `Editor.Content` | The layout that fills its container, with the toolbar above the text |
| `Editor.View` | The CodeMirror editor. Pass `value` and `onChange` when the text lives in your state |
| `Editor.Toolbar` | The formatting actions, as an `ActionToolbar` |
| `Editor.ToolbarMenu` | The same actions as a menu, for where a toolbar does not fit |
| `Editor.Blocks` | The part that draws the embedded blocks the extensions contribute |
| `Editor.BlockFrame` | The frame of one embedded block, which takes focus for it |
| `Editor.Diagnostics` | A developer panel of live editor state |

## Plain text

For plain text, the editor takes two sets of extensions:

- `createBasicExtensions` gives the editor its editing behavior, with options such as a placeholder and line wrapping.
- `createThemeExtensions` matches the app's light or dark theme. Read the mode with `useThemeMode`, and rebuild the
  extensions when it changes.

Rebuilding the extensions recreates the editor, so keep the editor's text in state and pass it as `value` with
`onChange`.

## Markdown with a toolbar

`createMarkdownExtensions` parses markdown, and `decorateMarkdown` styles it as you type.

`Editor.Toolbar` is an [`ActionToolbar`](/docs/tile/api/react-ui-menu/action-toolbar/), so its actions live in an atom.

Wrap your app in `RegistryProvider` from `@effect/atom-react`. This is best practice, because your app then controls
the registry that the toolbar reads. Without a provider, the toolbar reads the library's default registry.

Add the strings from `@dxos/react-ui-menu/translations` and `@dxos/react-ui-editor/translations` to the
`resourceExtensions` of `Theme.Provider`.

The toolbar is dimmed until its surface has the user's attention. Outside Composer, you set that up with two
components from `@dxos/react-ui-attention`:

- Put a `RootAttentionProvider` around the app.
- Put an `AttendableContainer` around the toolbar and the editor.

Then pass the container's id to the toolbar as `attendableId`.

## Bind the text to ECHO

An ECHO `Text` object from `@dxos/schema` holds a document's text. The `automerge` extension binds the editor to one of
the object's properties:

- Each edit goes into the object.
- Each change to the object, from another window or device, shows in the editor.

With the binding, `Editor.View` needs no `value`.
