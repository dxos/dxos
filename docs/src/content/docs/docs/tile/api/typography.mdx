```ts
import * as Typography from '@dxos/react-ui/Typography';
```

The first line is centred in a block, so text sits level with an icon or control however many lines it wraps to.

## Parts

| Part | What it is |
| --- | --- |
| `Typography.Text` | A paragraph, or another text element with `asChild` |
| `Typography.Link` | A link |
| `Typography.Crawl` | Lines that scroll up one at a time in a one-line window |
| `Typography.Timestamp` | A date or time |
