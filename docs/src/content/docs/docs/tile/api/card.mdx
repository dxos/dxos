A card is a block of related content and actions, one surface above its host. `Card.Header`, `Card.Body` and
`Card.Footer` share one content edge. With `grid`, rows put their icon in the start rail and trailing content in the
end rail.

## Parts

| Part | What it is |
| --- | --- |
| `Card.Root` | The card |
| `Card.Poster` | A full-width image at the top |
| `Card.Tile` | A tall leading tile with a large icon, beside the rest of the card |
| `Card.Header` | The row that holds `Card.Title`, with icons or buttons before and after it |
| `Card.Title` | The heading. It can clamp to a number of lines |
| `Card.Description` | Text under the title |
| `Card.Body` | The main content |
| `Card.Section` | Rows under an optional caption |
| `Card.Row` | A row of icon, text and trailing content. It is a button when it has `onClick` |
| `Card.Link` | A row that links out and opens in a new tab |
| `Card.Text` | A paragraph of text. `lines` clamps it, and `variant='muted'` reads as secondary text |
| `Card.Action` | An icon button for a `Card.Header` or `Card.Row`. Its click never activates the card |
| `Card.Menu` | A ⋮ button that opens a menu |
| `Card.Footer` | A group of actions at the end |
