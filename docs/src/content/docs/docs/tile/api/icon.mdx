## `Icon.Icon`

| Prop | Type | Effect |
| --- | --- | --- |
| `icon` | `string` | Names the icon, such as `ph--house--regular` |
| `label` | `string` | Sets an accessible name. Without one the icon is decorative |
| `size` | `Size` | Sets the size. The icon size of its surroundings by default |
| `hue` | `Icon.IconHue` | Colors the icon with a palette hue |
| `valence` | `'info' \| 'success' \| 'warning' \| 'error' \| 'neutral'` | Colors the icon by status |
| `tone` | `'muted' \| 'subtle'` | Dims the icon |
| `spin` | `boolean` | Spins the icon, for a busy state |

Most components that show an icon, such as `Button.Root`, `Menu.Item` and `Status.Empty`, take an `icon` name and draw it
themselves.
