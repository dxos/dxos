The trail scrolls sideways when it overflows.

## Parts

| Part | What it is |
| --- | --- |
| `Breadcrumb.Root` | The navigation landmark |
| `Breadcrumb.List` | The ordered trail |
| `Breadcrumb.Item` | One step, holding a Link or, last, the Current page |
| `Breadcrumb.Link` | An earlier step: a link, or a button with `asChild` |
| `Breadcrumb.Current` | The page the reader is on |
| `Breadcrumb.Separator` | The mark between steps, hidden from screen readers |
