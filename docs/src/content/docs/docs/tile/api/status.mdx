## Which to use

| Part                   | When                                                                            |
| ---------------------- | ------------------------------------------------------------------------------- |
| `Status.Progress`      | A task with a known fraction, an unknown one (`indeterminate`) or a deadline (`countdown`) |
| `Status.Steps`         | A task with named stages                                                        |
| `Status.Skeleton`      | Content is loading and its shape is known                                       |
| `Status.Deferred`      | Content is loading and may arrive at once. It shows the fallback only if the wait lasts |
| `Status.Empty`         | There is nothing to show: no items, no selection, no result                     |
| `Status.Error`         | A view failed. It shows the error and its stack                                 |
| `Status.ErrorBoundary` | A view below it may fail to render. It catches the error and shows `Status.Error` |

## `Status.Progress`

`Status.Progress` draws a bar for a task with a known fraction, an unknown one or a deadline.

| Prop | Type | Effect |
| --- | --- | --- |
| `value` | `number` | Sets how far through the task is, from 0 to `max` |
| `max` | `number` | Sets the value of a finished task, so `value` is a fraction of it. `1` by default |
| `indeterminate` | `boolean` | Shows a sweep, for a task with nothing to count |
| `error` | `boolean` | Draws the bar in the error color, where a run stopped |
| `countdown` | `number` | Sets the milliseconds to empty the bar over |
| `paused` | `boolean` | Holds a countdown where it is |
| `label` | `string` | Sets the accessible name |

## `Status.Deferred`

`Status.Deferred` shows a fallback only if the wait lasts. Use it when content is loading and may arrive at once.

- `pending` says whether to show the fallback.
- `delay` is how many milliseconds `pending` has to hold before the fallback appears.
- `minDuration` is the least time the fallback then stays.
- `fallback` is a function, so an expensive fallback costs nothing when it never shows.

With `delay` and `minDuration`, a fast load never flickers.

## `Status.Empty`

`Status.Empty` is the message for a view with nothing to show. Its children are the message, or the translated "No
items" when there are none. Use `icon` to add an icon above the message.

## `Status.Skeleton`

`Status.Skeleton` is a placeholder block. Use it when content is loading and its shape is known. `variant` is
`'default'`, `'circle'` or `'text'`.

## `Status.Steps`

`Status.Steps` shows progress through a task with named stages.

- `steps` is a count, or the stages themselves.
- `active` is the stage in flight.
- `fraction` is how far through that stage the task is.
