```ts
import * as Tabs from '@dxos/react-ui/Tabs';
```

The tabs sit above the content, or beside it when vertical. Arrow keys move along the tabs.

## Parts

| Part | What it is |
| --- | --- |
| `Tabs.Root` | Holds the selected tab |
| `Tabs.List` | The row of tabs |
| `Tabs.Trigger` | One tab |
| `Tabs.Indicator` | An underline that slides to the selected tab |
| `Tabs.Content` | The view for one tab |
