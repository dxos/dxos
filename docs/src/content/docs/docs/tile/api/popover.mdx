```ts
import * as Popover from '@dxos/react-ui/Popover';
```

A popover opens beside its trigger, in a portal, and closes when the user clicks elsewhere. With `modal`, it holds focus.

A popover has the parts of [`Dialog`](/docs/tile/api/dialog/) except `Footer`, plus `Popover.Anchor`. Use
`Popover.Anchor` to position the popover against an element other than its trigger.

`Popover.Content` draws an arrow toward the trigger by default. Pass `arrow={false}` to leave the arrow out.
