```ts
import * as Popover from '@dxos/react-ui/Popover';
```

A popover opens beside its trigger, in a portal, and closes when the user clicks elsewhere. With `modal` it holds focus.

The same parts as [`Dialog`](/docs/tile/api/dialog/), plus `Popover.Anchor` to position the popover against an element other than its trigger.
`Popover.Content` takes `arrow` to draw an arrow toward the trigger.
