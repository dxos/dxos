`Calendar` draws dates in two ways:

- `Calendar.Grid` is a scrolling grid of weeks. Use it when the user picks a day or a range.
- `Calendar.Week` is a week of hours with events in it.

Both sit inside `Calendar.Root`, which holds the date the calendar shows.

The package's strings come from `@dxos/react-ui-calendar/translations`. Add them to the theme provider's
`resourceExtensions`.

## Parts

| Part | What it is |
| --- | --- |
| `Calendar.Root` | Holds the date in view and the first day of the week (`weekStartsOn`) |
| `Calendar.Toolbar` | Names the month in view and jumps back to today |
| `Calendar.Grid` | Weeks of days that scroll; `rows` sets how many show |
| `Calendar.Week` | A week of hours, each event in its day's column; overlapping events share it |

## `Calendar.Grid`

`Calendar.Grid` shows weeks of days that scroll, and reports the day or the range the user picks.

| Prop | Type | Effect |
| --- | --- | --- |
| `rows` | `number` | How many weeks show |
| `dates` | `DateMarker[]` | Days to mark, each with a border for its `tag` |
| `initialDate` | `Date` | The day scrolled into view; today by default |
| `scrollMargin` | `number` | How many weeks stay above a day scrolled into view; `2` by default |
| `onSelect` | `({ date }) => void` | The user picked a day, with a click or an arrow key |
| `onSelectRange` | `({ range }) => void` | The user picked a range, with a drag or Shift and an arrow key |

## `Calendar.Week`

`Calendar.Week` draws a week of hours, with each event in its day's column. An event is an `id`, a `title`, a `start`
and an `end`.

The week reports gestures and holds no events of its own. This means you apply each change to your state.

| Prop | Type | Effect |
| --- | --- | --- |
| `date` | `Date` | Any day in the week to show; today by default |
| `events` | `CalendarEvent[]` | The events to draw |
| `onEventCreate` | `({ start, end }) => void` | The user dragged out an empty slot |
| `onEventUpdate` | `({ id, start, end }) => void` | The user moved an event or dragged its edge |

## Pick a day

`Calendar.Grid` scrolls through the weeks, and the toolbar names the month in view. The user clicks a day to pick it,
or drags across days to pick a range. `onSelect` reports the day, and `onSelectRange` reports the range.

## Plan a week

In `Calendar.Week`, the user drags an empty slot to add an event, drags an event to move it, or drags its edge to
resize it. The week calls `onEventCreate` or `onEventUpdate`, and you change the events you hold.
