`Globe` draws the countries itself on a canvas. This means it needs no tile server, works offline and sends no requests
to a third party. For a street map, use [`Map`](/docs/tile/api/react-ui-geo/map/).

The package's strings come from `@dxos/react-ui-geo/translations`.

## Parts

| Part | What it is |
| --- | --- |
| `Globe.Root` | Holds the center, zoom, rotation and translation; its `ref` gives a `GlobeController` |
| `Globe.Viewport` | Measures its space and sizes the canvas to it |
| `Globe.Canvas` | Draws the `topology`, and `features`: `points` and the `lines` between them |
| `Globe.Zoom` | Zoom in and out buttons |
| `Globe.Action` | Start and toggle buttons, for a spin or a tour |
| `Globe.Panel` | A panel at a corner of the viewport |
| `Globe.Debug` | The globe's state, for development |

The hooks act on the controller:

- `useDrag` turns the globe as the user drags.
- `useWheel` zooms with the wheel.
- `useSpinner` turns the globe on its own.
- `useTour` flies from point to point.
- `useGlobeZoomHandler` connects the zoom buttons.

## `Globe.Canvas`

`Globe.Canvas` draws the country outlines, and the points and lines you pass as `features`.

| Prop | Type | Effect |
| --- | --- | --- |
| `topology` | `Topology` | Country outlines from `loadTopology`; `110m` is the smallest |
| `features` | `{ points, lines, selected }` | Places as `lat` and `lng`, and lines from a `source` to a `target`; `selected` places draw above the rest |
| `projection` | `'orthographic' \| 'mercator' \| 'transverse-mercator' \| 'equirectangular' \| GeoProjection` | The projection, by name or as a d3 projection; `'orthographic'`, a globe, by default |
| `fit` | `'contain' \| 'cover'` | How the whole sphere sits in the canvas at zoom 1; unset keeps the projection's own scale |
| `styles` | `StyleSet` | Colors for each layer; the theme's by default |

## A trip on a globe

`useTour` flies from point to point and draws the arc it travels. It returns whether the tour is running, and a
setter that starts or stops it. The tour stops by itself after one pass over the points. With `loop`, the pass ends
back at the first point.
