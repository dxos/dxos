`Globe` draws the countries itself on a canvas, so it needs no tile server, works offline and sends no requests to a
third party. For a street map, use [`Map`](/docs/tile/api/react-ui-geo/map/). The package's strings come from
`@dxos/react-ui-geo/translations`.

## Parts

| Part | What it is |
| --- | --- |
| `Globe.Root` | Holds the zoom, rotation and translation; its `ref` gives a `GlobeController` |
| `Globe.Viewport` | Measures its space and sizes the canvas to it |
| `Globe.Canvas` | Draws the `topology`, and `features`: `points` and the `lines` between them |
| `Globe.Zoom` | Zoom in and out buttons |
| `Globe.Action` | A start button, for a spin or a tour |
| `Globe.Panel` | A panel at a corner of the viewport |
| `Globe.Debug` | The globe's state, for development |

The hooks act on the controller: `useDrag` turns the globe as the user drags, `useWheel` zooms with the wheel,
`useSpinner` turns it on its own, `useTour` flies from point to point, and `useGlobeZoomHandler` connects the zoom
buttons.

## `Globe.Canvas`

| Prop | Type | Effect |
| --- | --- | --- |
| `topology` | `Topology` | Country outlines from `loadTopology`; `110m` is the smallest |
| `features` | `{ points, lines }` | Places as `lat` and `lng`, and lines from a `source` to a `target` |
| `projection` | `'orthographic' | 'mercator' | ...` | A globe by default |
| `styles` | `StyleSet` | Colors for each layer; the theme's by default |
