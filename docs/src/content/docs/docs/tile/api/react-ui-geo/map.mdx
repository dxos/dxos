`Map` is a street map on Leaflet, drawn from map tiles, with markers and lines over it. It loads tiles from
OpenStreetMap unless you give it another server. For a map that needs no tile server, use
[`Globe`](/docs/tile/api/react-ui-geo/globe/).

## Parts

| Part | What it is |
| --- | --- |
| `Map.Root` | Holds the map; its `ref` gives a `MapController`, and `onChange` reports the center and zoom |
| `Map.Viewport` | The Leaflet frame, which takes focus |
| `Map.Tiles` | The tile layer; `url` is a tile URL template |
| `Map.Markers` | A marker per `GeoMarker`; `onSelect` gets the clicked marker's id |
| `Map.Lines` | Lines between places, such as a route |
| `Map.Zoom` | Zoom in and out buttons |
| `Map.Action` | A start button |

## `Map.Markers`

| Prop | Type | Effect |
| --- | --- | --- |
| `markers` | `GeoMarker[]` | Each an `id`, a `title` and a `location` |
| `lines` | `MapLine[]` | Lines the view fits around; `Map.Lines` draws them |
| `selected` | `string[]` | Ids of the markers to highlight |
| `onSelect` | `(id) => void` | The user clicked a marker |
