`Plot` draws a table of values as a chart. It fills its container and redraws when the container changes size. A
chart with more than one series has a legend.

## Props

| Prop | Type | Effect |
| --- | --- | --- |
| `data` | `PlotData` | Sets the columns and rows. The first column is the category or the x axis |
| `options.type` | `'bar' \| 'pie' \| 'xy' \| 'scatter' \| 'heatmap' \| 'radar' \| 'map'` | Sets the kind of chart. `'xy'` is a line chart |
| `options.grid` | `boolean` | Draws grid lines, on a bar or line chart |
| `options.stacked` | `boolean` | Stacks bars instead of standing them side by side |
| `options.horizontal` | `boolean` | Runs bars across |
| `options.regression` | `boolean` | Draws a trend line on a scatter chart |

## Chart a table

`toPlotData` turns rows into the chart's data. With `header`, the first row names the columns. The same data works for
every type, so you switch charts by changing one option.
