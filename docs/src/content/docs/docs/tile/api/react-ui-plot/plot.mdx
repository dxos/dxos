`Plot` draws a table of values as a chart. It fills its container and redraws when the container changes size. A
chart with more than one series has a legend.

## Props

| Prop | Type | Effect |
| --- | --- | --- |
| `data` | `PlotData` | Columns and rows; the first column is the category or the x axis |
| `options.type` | `'bar' | 'pie' | 'xy' | 'scatter' | 'heatmap' | 'radar' | 'map'` | The kind of chart |
| `options.grid` | `boolean` | Grid lines |
| `options.stacked` | `boolean` | Bars stack instead of standing side by side |
| `options.horizontal` | `boolean` | Bars run across |
| `options.regression` | `boolean` | A trend line on a scatter chart |
