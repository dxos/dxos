```ts
import * as Splitter from '@dxos/react-ui/Splitter';
```

A resizable divider can be dragged. In a narrow host the splitter shows one pane at a time.

## Parts

| Part | What it is |
| --- | --- |
| `Splitter.Root` | Holds the panes |
| `Splitter.Panel` | One pane |
| `Splitter.ResizeTrigger` | The divider |
| `Splitter.useContext` | Which pane shows, for a Back button or a list that opens a detail |
