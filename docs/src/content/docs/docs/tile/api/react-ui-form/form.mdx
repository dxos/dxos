`Form` builds a form from an Effect schema. Each property becomes a field of the right kind, its `title` annotation
becomes the field's label, and the schema's checks become the form's validation. Change the schema and the form
follows. Register the package's strings from `@dxos/react-ui-form/translations` with the theme provider.

## Parts

| Part | What it is |
| --- | --- |
| `Form.Root` | Takes the `schema` and the `values` or `defaultValues`; `onSave` gets the checked values |
| `Form.Viewport` | The form's container; with `scroll` it fills its parent and scrolls |
| `Form.Content` | The `form` element |
| `Form.Fields` | A field for each property of the schema, or of the properties in `include` |
| `Form.Field` | One row, bound to the form at `path` or holding controls of your own |
| `Form.FieldSet` | A labelled group of fields, which can fold |
| `Form.Layout` | The schema's fields laid out by a template |
| `Form.Actions` | Save and Cancel |
| `Form.Submit` | A submit button alone, with a label and icon of your own |
| `Form.ErrorText` | The text of a field's error |

`ObjectForm` is a `Form` over an ECHO object: it writes each change to the object as the user makes it.

## Render the form

`Form.Fields` renders a field for each property, and `Form.Actions` adds Save and Cancel. A field shows its error once
the user leaves it, and Save is disabled while a field the user touched has one. Save checks every value against the
schema, then calls `onSave` with them:
