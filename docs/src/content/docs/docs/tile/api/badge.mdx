A badge is a small mark on the corner of an avatar or icon. `Badge.Root` sizes to its child and places a
`Badge.Mark` on one of its corners. The mark is ringed in the surface color, so it reads as cut out.

## Parts

| Part | What it is |
| --- | --- |
| `Badge.Root` | The wrapper around an avatar or icon, which anchors `Badge.Mark` |
| `Badge.Mark` | The small glyph on the corner |
