The root sizes to its child and places a `Mark` on one of its corners, ringed in the surface colour so it reads as cut out.

## Parts

| Part | What it is |
| --- | --- |
| `Badge.Root` | Wraps an Avatar or Icon and anchors the Mark |
| `Badge.Mark` | The small glyph on the corner |
