These are the visible parts of a drag. The caller binds them to its own drag-and-drop logic.

## Parts

| Part | What it is |
| --- | --- |
| `DragHandle.DragHandle` | The six-dot grip button |
| `DragHandle.DropIndicator` | A line on the edge of a drop target |
| `DragHandle.DragPreview` | The chip shown under the pointer while dragging |
| `DragHandle.dragScope` | The data scope the parts share |
