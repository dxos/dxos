Buttons for common actions, each with its icon and translated label.

## Parts

| Part | What it is |
| --- | --- |
| `SystemButton.Add` | Adds |
| `SystemButton.Ai` | Runs an AI action |
| `SystemButton.Bookmark` | Bookmarks |
| `SystemButton.Cancel` | Abandons a form or dialog |
| `SystemButton.Check` | Marks one of several as chosen |
| `SystemButton.Clipboard` | Copies |
| `SystemButton.Close` | Closes |
| `SystemButton.Delete` | Deletes |
| `SystemButton.Disclosure` | Shows and hides a region |
| `SystemButton.Download` | Downloads |
| `SystemButton.Edit` | Edits |
| `SystemButton.Mic` | Records from the microphone |
| `SystemButton.Remove` | Takes a row out of a list without deleting what it names |
| `SystemButton.Save` | Commits a form or dialog |
| `SystemButton.Star` | Stars |
| `SystemButton.Upload` | Uploads |
