A system button is a button for a common action. Each one comes with its icon and translated label.

## Parts

| Part | What it is |
| --- | --- |
| `SystemButton.Add` | The add button |
| `SystemButton.Ai` | The button that runs an AI action |
| `SystemButton.Bookmark` | The bookmark toggle |
| `SystemButton.Cancel` | The button that abandons a form or dialog |
| `SystemButton.Check` | The toggle that marks one of several as chosen |
| `SystemButton.Clipboard` | The copy button |
| `SystemButton.Close` | The close button |
| `SystemButton.Delete` | The delete button |
| `SystemButton.Disclosure` | The button that shows and hides a region |
| `SystemButton.Download` | The download button |
| `SystemButton.Edit` | The edit button |
| `SystemButton.Mic` | The button that records from the microphone |
| `SystemButton.Remove` | The button that takes a row out of a list without deleting what it names |
| `SystemButton.Save` | The button that commits a form or dialog |
| `SystemButton.Star` | The star toggle |
| `SystemButton.Upload` | The upload button |
