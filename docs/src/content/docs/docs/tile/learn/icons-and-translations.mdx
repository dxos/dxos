By the end of this page the screen's own strings come from a translation resource, and the count says "1 contact" or
"3 contacts" as it should. Icons mark the email and the role, and an Add button creates a contact.

## Before you start

Our first toolbar wrote its count as `{contacts.length} contacts`, which says "1 contacts" when one is left. A
translation resource holds both forms of the string and picks one from the number:

- A **translation resource** maps keys to strings for each language. It files them under a **translation
  namespace**, a name that keeps one screen's keys apart from another's. Step 1 writes ours.
- `Hooks.useTranslation(ns)` returns `t`, which looks a key up in the user's language. If a key has `_one` and
  `_other` forms, the `count` we pass chooses between them. Steps 2 and 3 call it.

An icon needs no import. We name it in full, as a string, such as `ph--envelope--regular` for
[Phosphor](https://phosphoricons.com)'s envelope in the regular weight. `IconsPlugin` finds the names in our code and
puts those icons in the sprite, the one file of icons it builds.

[Translations and icons](/docs/tile/concepts/translations-and-icons/) explains how resources merge, and what happens
to an icon whose name the build did not see.
