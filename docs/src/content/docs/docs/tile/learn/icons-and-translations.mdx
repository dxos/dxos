By the end of this page every string the screen shows comes from a translation resource, the count says "1 contact"
or "3 contacts" as it should, and icons mark the email and the role. An Add button creates a contact.

## Before you start

An icon is named in full: `ph--envelope--regular` is Phosphor's envelope in the regular weight. `IconsPlugin` finds the
names in your code and puts those icons in the sprite, so there is nothing to import.

A translation resource maps keys to strings for each language, under a namespace. `useTranslation(ns)` returns `t`,
which looks a key up in the user's language. A key with `_one` and `_other` forms is chosen by the `count` you pass.
See [Translations and icons](/docs/tile/concepts/translations-and-icons/).
