This learning path builds a contacts screen: a list of people beside the selected person's details, with a toolbar to
add, edit and delete them. The first five pages keep the contacts in React state, so the only new thing on each page is
TILE. The last page stores them in [ECHO](/docs/echo/overview/).

By the end of this page the app shows two buttons in TILE's theme, in light or dark to match the system.

## Before you start

You need Node 20 or later. Every page of the path is the same app, so keep the project when you go on to the next one.
From the next page on, each page puts its version of the screen in a folder of its own, such as `src/layout/`, and
reuses pieces from the folders before it. The imports in the code name those folders.

<Steps>

1. **Make a Vite app.** Create a React and TypeScript project and install TILE's packages, as
   [Installation](/docs/tile/installation/) lists them:

   ```sh
   npm create vite@latest contacts -- --template react-ts
   cd contacts
   npm install @dxos/react-ui @dxos/ui-theme effect @effect/atom-react
   npm install --save-dev @dxos/vite-plugin-icons @phosphor-icons/core tailwindcss
   ```

2. **Configure Vite.** Replace `vite.config.ts` with the one in
   [Installation](/docs/tile/installation/#configure-vite). `ThemePlugin` generates the theme's CSS and `IconsPlugin`
   builds the icon sprite.

3. **Render the app inside the theme.** Replace `src/main.tsx`. It loads the two stylesheets, then renders the app
   inside `Theme.Provider`:

   <Snippet file="tile-tutorial/theme/main" region="main" lang="tsx" />

4. **Follow the system's light or dark setting.** Add this to the end of `src/main.tsx`. It sets the `dark` class
   that the dark tokens apply under:

   <Snippet file="tile-tutorial/theme/main" region="dark" lang="tsx" />

5. **Add the first buttons.** Replace `src/App.tsx`. `Layout.Flex` lays the buttons out in a row with a gap from the
   theme's scale, and `variant='primary'` marks the main action:

   <Snippet file="tile-tutorial/theme/App" region="app" lang="tsx" />

   Delete `src/App.css` and `src/index.css`, which Vite's template made. The theme replaces them.

</Steps>
