By the end of this page the detail column is a form: change a contact's name, email or role, then save or revert.

## Before you start

Each input sits in a `Field`, which ties its label to the control for screen readers and lines up labels, help text
and errors. `Input.Root` is a text input, and `Select` is a list of options in a popup. Both work controlled, with a
value and a change handler, the way React inputs do. See [Input](/docs/tile/api/input/) and
[Button](/docs/tile/api/button/).

<Steps>

1. **Write the editor.** It edits a copy of the contact, the draft, so nothing changes until Save. Save is disabled
   until the draft differs from the contact, and while the name is empty. Add `src/inputs/ContactEditor.tsx`:
