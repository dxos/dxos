By the end of this page the detail column is a form. You can change a contact's name, email or role, then save or
revert.

## Before you start

We build the form from three components:

- A `Field` holds one input. It ties the label to the control for screen readers, and lines up labels, help text and
  errors. Use one around every input that has a label.
- `Input.Root` is a text input. Use its `type` for one kind of text, such as the `'email'` of step 1.
- `Select` opens a list of options, and the user picks one. Use it when the choices are fixed, as our three roles
  are.

`Input.Root` and `Select` both work controlled, with a value and a change handler, the way React inputs do.
[Input](/docs/tile/api/input/) lists the other controls, such as checkboxes and switches, and
[Button](/docs/tile/api/button/) lists the button variants.
