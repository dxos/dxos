## Before you start

Built by hand, this screen is nested flex and grid boxes, each with its own padding and gap. TILE lays out a screen
with a few components that own their spacing, so we rarely write padding or flex classes:

- `Panel` is a frame with a header, a body that takes the remaining height, and an optional footer. Use it as the
  outer shell of a screen. Step 4 puts the screen in one.
- `Toolbar` is a row of controls and text. Use it in a panel's header.
- `Layout.Grid` places its children in tracks, and `Layout.Flex` places them in a row or a stack. Both take their
  gaps from the theme's scale. Use `Layout.Grid` when one track has a fixed size, as the list's column does in step 4.
- `ScrollArea` scrolls its content with the theme's scrollbar. Use it around content that can grow taller than its
  column, as the detail does in step 3.

[Layout](/docs/tile/concepts/layout/) explains how a panel passes its height down to the part that scrolls.

2. **List the contacts.** `Listbox` draws one row per item, with the label and a second line from `description`. It
   handles selection, arrow keys and typeahead. `Listbox.Viewport` makes the list scroll inside its column. Add
   `src/layout/ContactsScreen.tsx`:

   <Snippet file="tile-tutorial/layout/ContactsScreen" region="list" lang="tsx" />

   `value` is a list, because a listbox can allow several selections, so `onValueChange` takes the first id.

3. **Show the selected contact.** `Typography.Text` with `tone='muted'` reads as secondary text. When no contact is
   selected, `Status.Empty` shows an icon and a hint in the middle of the column:

   <Snippet file="tile-tutorial/layout/ContactsScreen" region="detail" lang="tsx" />

   Nothing on this page clears the selection, so we don't see the hint yet. It first shows in
   [Icons and translations](/docs/tile/learn/icons-and-translations/), after a delete.

4. **Put them in a panel.** The toolbar goes in `Panel.Header`. `cols={['16rem', 'fill']}` gives the list a fixed
   width and the detail the rest:

   <Snippet file="tile-tutorial/layout/ContactsScreen" region="screen" lang="tsx" />

   `Panel.Body asChild` makes the grid itself the body, so the grid fills the height under the toolbar and no extra
   element sits between them.

5. **Render the screen.** In `src/main.tsx`, render `<ContactsScreen />` in place of `<App />`, imported from
   `./layout/ContactsScreen.tsx`. Give it the window's height in `index.html`, so the panel fills it:

   ```html title="index.html"
   <div id="root" style="height: 100vh"></div>
   ```

</Steps>
