By the end of this page the contacts screen is a Vite app with TILE's theme. It shows its first two buttons, in light
or dark mode to match the system. TILE needs neither ECHO, DXOS's database, nor PLEX, its plugin framework, for this.

## Before you start

You need Node 20 or later. Every page of the path is the same app, so keep the project when you go on to the next one.

A component library usually ships a finished stylesheet. TILE generates its CSS when our app builds, so we install the
tools that build it beside the components. Step 1 installs seven packages, and sets the version of React:

- `@dxos/react-ui` holds the components. It needs React 19.3, which is why step 1 names a version of `react` and
  `react-dom`.
- `@dxos/ui-theme`, its peer, holds the tokens and `ThemePlugin`, a Vite plugin that turns them into CSS. A **token**
  is a named color or size that the components read. We set the plugin up in step 2.
- `effect` and `@effect/atom-react` are peers of `@dxos/react-ui` too, so we install them beside it.
- `@dxos/vite-plugin-icons` holds `IconsPlugin`, which gathers the icons the app draws into one file.
- `@phosphor-icons/core` holds the icons themselves, as SVG files that `IconsPlugin` reads.
- `tailwindcss` is the compiler that `ThemePlugin` runs.

Until the next npm release, we install the `@dxos` packages from pkg.pr.new, as the build of main that these pages
describe. The releases on npm are older and do not all run outside the DXOS repository. ECHO's
[Installation](/docs/echo/learn/installation/) installs its packages from the same build.

<Steps>

1. **Make a Vite app.** Create a React and TypeScript project and install the packages:

   ```sh
   npm create vite@latest contacts -- --template react-ts
   cd contacts
   npm install \
     https://pkg.pr.new/dxos/dxos/@dxos/react-ui@20a14b9 \
     https://pkg.pr.new/dxos/dxos/@dxos/ui-theme@20a14b9 \
     effect@4.0.4 @effect/atom-react@4.0.4 react@~19.3.1 react-dom@~19.3.1
   npm install --save-dev \
     https://pkg.pr.new/dxos/dxos/@dxos/vite-plugin-icons@20a14b9 \
     @phosphor-icons/core tailwindcss
   ```

   Install any other `@dxos` package from the same build, with its name in place of `react-ui`.

2. **Configure Vite.** Replace `vite.config.ts`. Two plugins do the work:

   - `ThemePlugin` generates the theme's CSS with Tailwind. Tailwind emits a token or a class only when a file it
     scans names it, so `content` points it at the components' own stylesheets.
   - `IconsPlugin` builds `/icons.svg`, a **sprite**, which is one file that holds every icon our code and the
     components name.

   ```ts title="vite.config.ts"
   import react from '@vitejs/plugin-react';
   import { join } from 'node:path';
   import { defineConfig } from 'vite';

   import { ThemePlugin } from '@dxos/ui-theme/plugin';
   import { IconsPlugin, iconSymbolPattern } from '@dxos/vite-plugin-icons';

   const phosphor = join(import.meta.dirname, 'node_modules/@phosphor-icons/core/assets');

   export default defineConfig({
     plugins: [
       ThemePlugin({ content: ['node_modules/@dxos/*/src/**/*.css'] }),
       IconsPlugin({
         symbolPattern: iconSymbolPattern({ sets: ['ph'] }),
         assetPath: (_set, name, variant) =>
           join(phosphor, variant, variant === 'regular' ? `${name}.svg` : `${name}-${variant}.svg`),
         spriteFile: 'icons.svg',
         contentPaths: [join(import.meta.dirname, 'src/**/*.{ts,tsx}')],
         // Pre-bundled dependencies skip the plugin's transform, so their icons are found by scanning up front.
         scanPaths: [join(import.meta.dirname, 'node_modules/@dxos/*/dist/**/*.mjs')],
       }),
       react(),
     ],
   });
   ```

   `ThemePlugin` also gives the app dark mode. The dark value of every token applies under a `dark` class on the root
   element. The plugin adds a script to the page's `<head>` that sets the class from the system's setting before the
   first paint, and sets it again when the setting changes.

   To let the user choose the mode instead, see [Custom themes and dark mode](/docs/tile/guides/custom-themes/),
   which sets the class from a stored choice.

3. **Render the app inside the theme.** Replace `src/main.tsx`. The new file imports two stylesheets before any
   component:

   - `@dxos-theme` is the virtual module that `ThemePlugin` serves.
   - `@dxos/react-ui/theme.css` holds the components' own rules.

   Then it renders the app inside `Theme.Provider`, which gives every component the strings its built-in labels read
   and the icons it draws:

   <Snippet file="tile-tutorial/theme/main" region="main" lang="tsx" />

   `resourceExtensions={translations}` passes react-ui's own strings, such as the "No items" of an empty list.
   `tx` takes a theme function, and `Theme.defaultTx` is the one TILE exports.

4. **Add the first buttons.** Replace `src/App.tsx`. `Layout.Flex` lays the buttons out in a row with a gap from the
   theme's scale, and `variant='primary'` marks the main action:

   <Snippet file="tile-tutorial/theme/App" region="app" lang="tsx" />

   Delete `src/App.css` and `src/index.css`, which Vite's template made. The theme replaces them.

</Steps>
