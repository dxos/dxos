By the end of this page the contacts screen is a Vite app with TILE's theme, and shows its first two buttons in light
or dark to match the system. TILE needs no ECHO or PLEX for this.

## Before you start

You need Node 20 or later. Every page of the path is the same app, so keep the project when you go on to the next one.

`@dxos/react-ui` holds the components. `@dxos/ui-theme`, its peer, holds the tokens and a Vite plugin that turns them
into CSS. Until the next npm release, install `@dxos` packages the way [ECHO's Installation](/docs/echo/learn/installation/)
does.

<Steps>

1. **Make a Vite app.** Create a React and TypeScript project and install TILE's packages:

   ```sh
   npm create vite@latest contacts -- --template react-ts
   cd contacts
   npm install @dxos/react-ui @dxos/ui-theme effect @effect/atom-react
   npm install --save-dev @dxos/vite-plugin-icons @phosphor-icons/core tailwindcss
   ```

2. **Configure Vite.** Replace `vite.config.ts`. Two plugins do the work:

   - `ThemePlugin` generates the theme's CSS with Tailwind. Tailwind emits only the classes that a scanned file names,
     so `content` points it at the components' own stylesheets.
   - `IconsPlugin` builds `/icons.svg`, a sprite of every icon your code and the components name.

   ```ts title="vite.config.ts"
   import react from '@vitejs/plugin-react';
   import { join } from 'node:path';
   import { defineConfig } from 'vite';

   import { ThemePlugin } from '@dxos/ui-theme/plugin';
   import { IconsPlugin, iconSymbolPattern } from '@dxos/vite-plugin-icons';

   const phosphor = join(import.meta.dirname, 'node_modules/@phosphor-icons/core/assets');

   export default defineConfig({
     plugins: [
       ThemePlugin({ content: ['node_modules/@dxos/*/src/**/*.css'] }),
       IconsPlugin({
         symbolPattern: iconSymbolPattern({ sets: ['ph'] }),
         assetPath: (_set, name, variant) =>
           join(phosphor, variant, variant === 'regular' ? `${name}.svg` : `${name}-${variant}.svg`),
         spriteFile: 'icons.svg',
         contentPaths: [join(import.meta.dirname, 'src/**/*.{ts,tsx}')],
         // Pre-bundled dependencies skip the plugin's transform, so their icons are found by scanning up front.
         scanPaths: [join(import.meta.dirname, 'node_modules/@dxos/*/dist/**/*.mjs')],
       }),
       react(),
     ],
   });
   ```

3. **Render the app inside the theme.** Replace `src/main.tsx`. It imports two stylesheets before any component:
   `@dxos-theme`, the virtual module `ThemePlugin` serves, and `@dxos/react-ui/theme.css`, the components' own rules.
   Then it renders the app inside `Theme.Provider`, which gives every component the theme and the strings its
   built-in labels read:

   <Snippet file="tile-tutorial/theme/main" region="main" lang="tsx" />

4. **Follow the system's light or dark setting.** The dark values of every token apply under a `dark` class on the
   root element. Add this to the end of `src/main.tsx`. It sets the class before the page paints and keeps it in step
   with the system:

   <Snippet file="tile-tutorial/theme/main" region="dark" lang="tsx" />

   To let the user choose instead, see [Custom themes and dark mode](/docs/tile/guides/custom-themes/).

5. **Add the first buttons.** Replace `src/App.tsx`. `Layout.Flex` lays the buttons out in a row with a gap from the
   theme's scale, and `variant='primary'` marks the main action:

   <Snippet file="tile-tutorial/theme/App" region="app" lang="tsx" />

   Delete `src/App.css` and `src/index.css`, which Vite's template made. The theme replaces them.

</Steps>

## Try it

Run `npm run dev` and open the page. Switch your system between light and dark, and the buttons follow. This preview
follows the docs' own theme picker instead:

## What you can do now

You can render TILE components in a themed app that follows light and dark. Next,
[Lay out a screen](/docs/tile/learn/lay-out-a-screen/) builds the list and the detail beside it. From there on, each
page puts its version of the screen in a folder of its own, such as `src/layout/`, and reuses pieces from the folders
before it.
