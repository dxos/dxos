By the end of this page the contacts are ECHO objects. They are stored on the device, sync to your other devices and to
anyone you share the space with, and the edit dialog is a form built from their schema.

## Before you start

This page uses ECHO, DXOS's database, through its React hooks. Add the bundler settings from step 2 of
[ECHO's Installation](/docs/echo/learn/installation/) to `vite.config.ts`, so the database's worker and WebAssembly load.
Then install the React client and the form package:

```sh
npm install @dxos/react-client @dxos/react-ui-form
```

Three things change from the last page:

- A **type** replaces the `Contact` type. ECHO checks and syncs objects of a type it knows.
- `useQuery` replaces `useState` for the list. It returns the objects that match, and renders again when one is
  added or removed, here or on another device.
- `useObject` reads one object. A component that reads an object's fields this way renders again when that object
  changes.

## Try it

Run the app and add a few contacts. Reload, and they are still there. Open the app in a second browser profile and
join the space as [Sharing](/docs/echo/learn/sharing/) shows, and edits in one window appear in the other.

## What you can do now

You have a screen built with TILE whose data lives in ECHO. From here:

  [Editor](/docs/tile/api/react-ui-editor/editor/).
- [TILE in a PLEX plugin](/docs/tile/guides/tile-in-a-plex-plugin/) shows how this screen would become a Composer
  plugin.
