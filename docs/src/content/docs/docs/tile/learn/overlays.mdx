## Before you start

Our screen needs four things to appear above the page: an editor, a question, a hint and a notice. Which component
draws each one? An **overlay** is a component that TILE draws above the page, and we use four of them:

- A `Dialog` is modal. The page behind it is inert until it closes. Use it for a task the user finishes or cancels
  before going on, as step 1 does for the editor.
- A `Popover` opens beside its trigger and closes when the user clicks elsewhere. Use it for short content that
  belongs to one control, as step 2 does for the delete question.
- A `Tooltip` shows a short hint on hover or focus. Use it to name a control or explain a value, as step 3 does for
  the role. It never takes focus, so put nothing in it that the user has to click.
- A `Toast` reports something that happened and goes away by itself. Use it when the user does not have to answer,
  as step 4 does for a save.

A dialog, a popover and a tooltip each have a `Trigger` that opens it and a `Content` that holds it. `asChild` on a
trigger makes our button the trigger. Without it, the trigger wraps our button in a button of its own.

A toast has neither. It is open while `open` on its `Toast.Root` is true.

[Dialog](/docs/tile/api/dialog/), [Popover](/docs/tile/api/popover/), [Tooltip](/docs/tile/api/tooltip/) and
[Toast](/docs/tile/api/toast/) list the parts of each. TILE has more overlays than these four, such as
[Menu](/docs/tile/api/menu/) for a list of actions and [AlertDialog](/docs/tile/api/alert-dialog/) for a question the
user must answer.

## Try it

Choose a contact and press Edit. Save a change, and the toast appears. Hover over the role, or tab to it, to see what
the role allows. Press Delete, then Keep or Delete.

## What you can do now

You can open dialogs and popovers from buttons, add tooltips to any element, and show toasts. Next,
[Icons and translations](/docs/tile/learn/icons-and-translations/) moves the screen's strings into a resource.
