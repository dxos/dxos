DXOS is a stack for building local-first and agentic software. Apps keep their data on the user's own devices, sync
with the people they share it with, and keep working offline. The stack is a set of independent pieces. You can adopt
any one of them on its own, and each gets stronger next to the others. An app built from plugins gets sync for free
when its data is in ECHO, and an agent works in that same data through typed operations. Most
people start with ECHO, the data layer the rest build on.
