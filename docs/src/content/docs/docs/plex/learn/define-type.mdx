By the end of this page the plugin has a Stashed link type, and the inspector lists its fields.

## Background

A plugin's data is ECHO objects, and a type describes them. In a database, a table definition says which columns a
row has. A type does the same for an object, and it also carries annotations.

The app reads the type's annotations to name an object, pick its icon, and decide whether a person can create one. We
set all three in step 1.

The app can create, name and list an object only if a plugin has registered its type. We register ours in step 3.

[Defining types](/docs/echo/learn/defining-types/) and the [Type](/docs/echo/api/type/) guide cover types in full.
This page uses only what PLEX needs.

## Steps

1. **Declare the type.** `Type.makeObject` makes the schema an ECHO type. It takes the type's DXN, the DXOS name for
   a resource, which here is a typename and a version. The fields are optional because a new object starts empty.

   <Snippet file="plex-tutorial/src/types/StashedLink" region="type" />

   `LabelAnnotation` names `title` as the field that labels a link, and `IconAnnotation` gives the type its icon and
   hue. `UserType` marks the type as one a person creates, which puts it in the app's create menus.

2. **Add a factory.** `make` fills in defaults, so every caller creates a link the same way.

   <Snippet file="plex-tutorial/src/types/StashedLink" region="make" />

3. **Register the type with the app.** The schema module's file has one default export, the list of the plugin's
   types.

   <Snippet file="plex-tutorial/src/capabilities/schema" region="schema" />

4. **Name the type.** The app labels a type with strings from the type's own namespace, which is its typename. Add an
   entry for it to the translations, after the plugin's own.

   <Snippet file="plex-tutorial/src/translations" region="type" />

   `typename.label` is the name the **+** menu shows, and `object-name.placeholder` names a new link until the person
   gives it a title.

5. **Add the module to `dx.config.ts`.** `AppCapability.schema` is the module maker for types. It turns the list from
   step 3 into a contribution to the `Schema` capability.

   <Snippet file="plex-tutorial/dx.config" region="schema" />

6. **See the type.** Click **Load dev plugin** below, or **Reload** if your plugin is loaded already, and select
   **Schema**. The module lists the Stashed link type with its fields.

   <InspectorEmbed adds={['schema']} />

   We have no way to create a link yet. Creating one runs an operation, and the next page adds operations.

## What you can do now

You can declare a type with the annotations the app reads, register it so the app can create and list its objects,
and name it in the plugin's translations.
