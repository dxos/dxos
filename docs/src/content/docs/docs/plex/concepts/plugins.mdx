A plugin is metadata plus a set of modules. A PLEX app is the plugins it loads.

## Model

In most web apps, a feature is code that the app imports and runs at startup. In PLEX, a feature is a plugin. A
plugin describes itself, and it splits its work into parts that each wait for an event.

A plugin has two parts:

- Its **metadata** names it: a key that no other plugin uses, a display name, a description and an icon.
- Its **modules** do the work. Each module activates on an event, runs once, and contributes
  [capabilities](/docs/plex/concepts/capabilities/).

The capabilities a module contributes are typed values, such as a surface component or an operation handler, that
other modules look up.

You build a plugin with three calls. `Plugin.define` takes the metadata, `Plugin.addModule` adds each module, and
`Plugin.make` returns a function that the app's plugin manager calls to create the plugin.

## Behavior

- A module is **inline** or **lazy**. `Capability.inlineModule` carries its body with it. `Capability.lazyModule`
  names a loader, and the plugin manager imports the body only when the module's event fires. A module whose event
  never fires never loads, so a plugin costs nothing until it is used.

- The module makers in `AppCapability`, such as `AppCapability.surface`, fix a module's capability and its event.
  This means a manifest names only the file to load. The compiler checks the loader's default export against the
  capability.
- Every module declares what it `provides` and what it `requires`. The plugin manager uses them to order activation.
  See [Activation](/docs/plex/concepts/activation/) for the rules.
- Plugins never import each other's modules. To extend another plugin, you contribute to a capability that plugin
  reads.

## Limits

- A plugin's key is a reverse-domain name, and its last segment must be camelCase. Keep the key once the plugin has
  users, because settings and enabled state are stored under it.
- A module keeps no state between activations. What it needs to keep, it contributes or stores.
