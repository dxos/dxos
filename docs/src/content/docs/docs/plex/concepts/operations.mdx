An operation is an action with a name, a typed input and a typed output, defined once and run from anywhere in an
app, by people and by agents.

## Model

An operation **definition** has a key (a DXN), metadata for people and agents, and schemas for its input and output. A
**handler** is an Effect that takes the input and returns the output. Definitions and handlers are separate values, so a
plugin can export a definition for other plugins to call without exposing how it runs.

<Snippet file="app-framework-tutorial/src/types/StashedLinkOperation" region="operation" />

Plugins contribute handlers in an **operation handler set** through the `OperationHandler` capability. The **operation
invoker** looks up the handler by the definition's key and runs it. Any module, handler or graph action can invoke an
operation with `Operation.invoke`; a component uses `useOperation`.

<Snippet file="plex-concepts" region="invoke" />

A **skill** hands operations to the assistant. It is a name, instructions, and a list of operations that become the
assistant's tools; a plugin contributes it through `AppCapabilities.SkillDefinition`.

## Behavior

- One definition serves three callers. A button invokes it through a hook. The command palette lists it. A skill hands
  it to the assistant as a tool, and the assistant reads the schema descriptions to fill in the input. None of the three
  needs code of its own.
- The invoker validates the input against the schema before the handler runs, and the output after.
- Errors are typed. A handler fails with tagged errors that a caller catches by tag, and invoking an operation that no
  plugin handles fails with `NoHandlerError`.
- An operation can be undone. A plugin contributes an `UndoMapping` that names the operation's inverse and derives the
  inverse's input from the forward input and output; the app records each undoable invocation and offers to undo it.

<Snippet file="plex-concepts" region="undo" />

- Handlers load lazily. A lazy handler set names each handler's module, and the framework imports it the first time the
  operation is invoked.
- The App Toolkit defines operations every plugin can call. `LayoutOperation.Open` opens items by path,
  `LayoutOperation.Close` closes them, and `SpaceOperation.AddObject` adds an object to a space.

## Limits

- A handler runs with the services its definition declares, plus the operation service for invoking other operations.
  It does not get the React tree.
- An operation's input must be serializable for the assistant to call it. Pass objects by reference where the caller is
  an agent.
- Undo replays the inverse operation; it does not restore a snapshot. An operation whose effect cannot be inverted
  from its input and output is not undoable.
