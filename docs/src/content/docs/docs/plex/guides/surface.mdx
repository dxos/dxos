```ts
import * as Surface from '@dxos/app-framework/Surface';
import * as AppSurface from '@dxos/app-toolkit/AppSurface';
```

`Surface` creates surface contributions and renders surfaces. `AppSurface` holds the App Toolkit's roles and the
filters that match them.

See [Surfaces](/docs/plex/concepts/surfaces/) for how matching works.

## Contribute a surface for an object type

`Surface.create` makes a surface contribution. It takes an id, a filter, a component and a `props` mapper.

`AppSurface.object(role, Type)` is the filter for an object type. It matches a role when the data's subject is an
object of the type.

## Match on data and set the order

`AppSurface.oneOf` matches any of several filters. Use it when one component fits more than one role.

`AppSurface.allOf` requires all of them.

Other filters match one thing each:

- `AppSurface.literal` matches a literal value.
- `AppSurface.companion` matches the object a companion panel is attached to.
- `AppSurface.subject` matches a subject that passes a predicate you give it.

When several surfaces match, `position` on the contribution orders them. Pass `Position.first` or `Position.last` from
`@dxos/util` to come before or after the rest.

## Render a nested surface from a component

`Surface.Surface` renders whatever surface matches a role and data. Use it when your component shows something that
another plugin knows how to render. Pass `limit` to cap how many render.

## The standard roles

| Role | Where it renders | Data |
| --- | --- | --- |
| `Article` | The main content area, one object per plank. | `{ subject, attendableId }` |
| `Section` | An object inside a stack or another document. | `{ subject, attendableId }` |
| `CardContent`, `CardIcon` | The body and the leading picture of an object's card. | `{ subject }` |
| `CardMenu` | Menu items for an object's card. | `{ subject, menu }` |
| `ObjectProperties` | The properties panel of an object. | `{ subject }` |
| `Dialog`, `Popover` | A dialog or popover opened by an operation. | `{ component, props }`, set by the caller. |
| `StatusIndicator` | The status bar. | None. |
| `deckCompanion(variant)` | A workspace-wide panel beside the deck. | `{ id?, subject? }` |

## Members at a glance

| Member | Summary |
| --- | --- |
| `Surface.create` `createWeb` | Make a surface contribution from a React component or a web component |
| `Surface.Surface` | Render the surfaces that match a role and data |
| `Surface.useIsAvailable` | Get a function that checks whether a surface matches a role and data |
| `Surface.makeFilter` | Make a filter from a role and a guard |
| `AppSurface.object` `snapshot` | Match a role when the subject is an object of a type, or a snapshot of one |
| `AppSurface.literal` `subject` `component` | Match a literal subject, a subject that passes a predicate, or a named dialog |
| `AppSurface.companion` | Match the object a companion panel is attached to |
| `AppSurface.oneOf` `allOf` | Match any of several filters, or all of them |
| `AppSurface.Article` `Section` `CardContent` | The roles a plugin fills most often |
| `AppSurface.deckCompanion` | Make the role of a panel beside the deck |

The full list is in the [API reference](/docs/plex/resources/api-reference/).
