A plugin's components reach the rest of the app through hooks. With the hooks on this page, your component can read
capabilities, invoke operations and read settings.

The hooks work in any component under the app's plugin manager, which every surface is.

## Read capabilities from a component

`useCapability` returns a singleton capability. `useCapabilities` returns every contribution to a multi capability.
Both re-render the component when contributions change.

`useOptionalCapability` returns `undefined` when no plugin provides the capability. Use it when your component can
work without one.

## Invoke operations from a component

`useOperation` binds an operation to a callback. Its argument maps the callback's arguments to the operation's input.

`useOperationInvoker` returns the invoker, whose `invokePromise` returns the operation's output. Use it when your
component needs that output.

## Read plugin settings and translations

`useAtomCapability` reads an atom capability, such as a plugin's settings, and re-renders when it changes.
`useAtomCapabilityState` also returns a setter. Use it when the component changes the value.

`useTranslation` from `@dxos/react-ui/Hooks` takes the plugin's namespace.

## The reactivity rules

In React, a component re-renders when its props or state change. A field of an ECHO object is neither, so a plugin's
component follows three rules:

- Reading an ECHO object's field in render does not subscribe the component. Use `useObject` for a snapshot that does,
  and `useQuery` for a list. See the ECHO [React guide](/docs/echo/guides/react/).
- Write objects inside `Obj.update`, from an event handler or an operation, never during render.
- Never assume your component is the only view of an object. The same object can be open in another plank, on another
  device, or in the assistant's hands.

## Members at a glance

| Member | Summary |
| --- | --- |
| `useCapability` `useCapabilities` | Read a singleton capability, or every contribution to a multi capability |
| `useOptionalCapability` `useOptionalCapabilities` | Read a capability that may have no provider |
| `useAtomCapability` `useAtomCapabilityState` | Read an atom capability, with or without a setter |
| `useOptionalAtomCapability` | Read an atom capability that may have no provider |
| `useOperation` | Bind an operation to a callback |
| `useOperationInvoker` | Get the invoker, to run an operation and read its output |
| `ToolkitHooks.useActiveSpace` `useAppGraph` `useLayout` | Read app state, from `@dxos/app-toolkit/Hooks` |
| `UiHooks.useTranslation` | Read a string by its key, from `@dxos/react-ui/Hooks` |

The full list is in the [API reference](/docs/plex/resources/api-reference/).
