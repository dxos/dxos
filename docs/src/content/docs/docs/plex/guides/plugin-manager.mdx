The plugin manager holds an app's plugins, decides which are enabled, and activates their modules as events fire. An
app such as Composer creates one at boot. Your plugin reaches it through `Capabilities.PluginManager` when it needs to
turn other plugins on or off.

See [Activation](/docs/plex/concepts/activation/) for the order it activates modules in.

## Create a plugin manager

`PluginManager.make` creates a manager. It takes the plugins the app knows about and the ones enabled at start.
Plugins tagged `system` are always enabled.

The `pluginLoader` turns an id into a plugin when the manager is later asked to add one.

## Enable, disable and remove plugins

You can change which plugins are on while the app runs.

- `enable` turns on a plugin and the plugins it declares in `dependsOn`. It then activates every module whose event
  has fired.
- `disable` deactivates a plugin's modules and, by default, the plugins that depend on it.
- `remove` disables a plugin and forgets it.

## Load a plugin from a URL

`add` hands an id to the plugin loader and registers the result without enabling it.

`UrlLoader.make` makes a loader that loads a plugin from its manifest URL. This is how Composer's Load dev plugin and
the docs' [inspector](/docs/plex/guides/debugging/) load a plugin from its dev server.

## Read which plugins and modules are active

Each piece of state has a getter and an atom.

- Use the getter for a one-off read.
- Use the atom in a component that should update.

`getFailed` lists the plugins that failed to load or activate, with the phase and the error.

## Members at a glance

| Member | What it does |
| --- | --- |
| `make(options)` | Creates a manager. |
| `start()`, `activate(event)` | Runs startup; fires an event. |
| `add(id)`, `enable(id)`, `disable(id)`, `remove(id)` | Changes which plugins are loaded and on. |
| `plugins`, `enabled`, `active`, `failed` | Atoms of the manager's state; each has a `get…` reader. |
| `getDependencies(id)`, `getDependents(id)` | The plugins a plugin needs, or that need it. |
| `capabilities` | The capability manager that holds every contribution. |
