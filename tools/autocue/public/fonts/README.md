# Fonts

Put the licensed Sharp Sans file here:

    public/fonts/SharpSansDispNo1-Medium.ttf

It is ignored by git. Without it, videos render in Helvetica Neue / Arial.

DM Sans and DM Mono (SIL Open Font License, from the DXOS brand kit) are committed: the Saas2D video uses them for
headings, labels and cards.
