# Packages a plugin's EDGE build must not reach: every export subpath that declares a `workerd`
# condition (normally `./XPlugin`, which EDGE's operation-service bundles). Enforced by the
# `check-server-imports` task (.moon/tasks/tag-composer-plugin.yml) through
# `dx-trace-imports --to-file`. One package, subpath or glob per line; `#` starts a comment.
#
# A workerd build needs schema, operation handlers, skills and connectors. A ban here means the
# package has no use on EDGE; fix a violation at its source (an `environments` list without
# `workerd`, a subpath instead of a barrel, a per-runtime `#import`) rather than here.
#
# A `!` line exempts a subpath of a banned package. The tracer then walks into the files it resolves
# to, so the subpath still fails the check if it imports anything banned.
#
