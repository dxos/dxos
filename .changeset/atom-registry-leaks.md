'@dxos/effect': minor

Graphs, menus and static trees keep atoms in the app's atom registry only for as long as the thing they belong to. An app graph pins each node's atom while the node is in the graph and releases it on `release` or when the graph is disposed with the new `AppGraph.dispose(graph)`; the app graph plugin disposes its graph, and `useOwnedGraph` from `@dxos/react-ui-menu` disposes a graph built during render when its deps change, when the component unmounts, or, for a render React discarded, once that render is collected. `AtomEx.makeOwned(owner, atom)` keeps an atom mounted while `owner` is alive and releases it once `owner` is garbage-collected; an owner implements `AtomEx.Owner`, exposing its atom registry and its class's static `FinalizationRegistry` under the `AtomEx.OwnerId` symbol; a graph model's version atom, a graph builder's extensions and a menu's contributions use it. Other graph atoms (edges, connections, actions) are views kept only while read: subscribe to them with `{ immediate: true }` or read them with `useAtomValue`.
