A head EDGE lists beyond the local ones is confirmed from storage when it is a stored commit or fragment head, before the document is loaded to check it. Confirmations lived only in memory, so every boot loaded and synced each in-sync document whose EDGE heads include a fragment head: on a 3,400-document profile, 40 documents and ~30 MB of reads per boot, which set the ECHO worker's Automerge and Subduction wasm memories at ~40 MiB each.
