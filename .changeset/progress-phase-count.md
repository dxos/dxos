Clear a phase's item count when the run enters the next one. A producer says a phase cannot be
counted by sending no total, but `total` is an optional schema field — an explicit `undefined` and an
absent one are the same bytes on the wire — so the trace sink kept the previous phase's numbers and
drew a determinate bar over work it could not measure. Magazine curation showed this as `0 / 1` (the
feed count from phase 0) while phase 1's single opaque agent call was in flight.
