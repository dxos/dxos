Agents are managed under space settings (Settings → Agents), where they are added and deleted, and each agent has Discord and Email companions for connecting it to a Discord server or giving it an email address. Breaking: `Agent` is no longer a user type, so agents no longer appear in the content tree, the create dialog or search, and an agent's channels belong to it and are deleted with it.
