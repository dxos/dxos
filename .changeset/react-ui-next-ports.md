`@dxos/react-ui/next` adds `Avatar`, `Tabs`, `Main`, `Progress`, `Splitter` and `Toast`, Next counterparts of the
current components built on Ark primitives with Ark part names, `.nx-*` theme rules and per-size stories, so callers of
the current components have a target for the migration.
