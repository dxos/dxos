`@dxos/react-ui/next` adds Next counterparts for every current component that had none: `Avatar`, `Tabs`, `Main`,
`Progress`, `Splitter`, `Toast`, `ErrorFallback`, `Focus`, `ScrollContainer`, `Accordion`, `Carousel`, `MediaPlayer`,
`QrCode`, `Link`, `Skeleton`, `Deferred`, `Timestamp`, `AttentionGlyph`, `Breadcrumb`, `HoverCard`, `MenuButton`,
`Tour`, `FloatingPanel`, `Slider`, `Steps`, `Editable` and `TextCrawl`. They are built on Ark primitives with Ark part
names where Ark has one, styled by `.nx-*` theme rules, so every current component now has a migration target.
