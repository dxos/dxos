`@dxos/react-ui/next` exports the next-generation `Next.*` primitives: Container, ScrollArea, Toolbar, Field, FieldSet,
Input, Textarea, DateInput, Select, Combobox, Checkbox, Switch, Button, IconButton, ToggleIconButton, Dialog, Popover,
Menu, Tooltip, Card, Image, Collapsible, Tag and more. Load their styles once with
`import '@dxos/react-ui/next/theme.css'`. The existing `@dxos/react-ui` components are unchanged; the new namespace sits
beside them so plugins can adopt it one component at a time.
