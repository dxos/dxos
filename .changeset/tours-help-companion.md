Add guided tours. A plugin registers a tour against a predicate over a graph node's data, so a tour can belong to an object type or to the app itself, and other plugins contribute step fragments to any tour running on a subject their feature applies to. A help companion offers the tours that match the object beside it, and a tour marked automatic runs once, unprompted, the first time a matching object is opened in a profile with an account. Every space's Home now has a help companion that introduces the app and starts the welcome tour, and the companion pane starts open on help, closing only when the reader closes it. A "Hide help panels" setting removes the help companions.
