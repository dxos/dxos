Add guided tours. A plugin registers a tour against a predicate over the rendered node's data, so a tour can belong to an object type or to the app itself, and other plugins contribute step fragments into whatever tour is running where their feature applies. Tours are offered from an article's help companion and can run once unprompted on the first object of a type a user opens. The companion pane now opens on help with a new object, until the reader closes it.
