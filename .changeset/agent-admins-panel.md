Profile › Agents lists the agents you administer, read from their own spaces (`AgentSpace`), while the identities setting is on, each with a link to every space it shares with you. Account panels carry explicit positions (`Account.position`), so another plugin can place a panel between two of them. Settings › Agents › Add agent no longer adds a second agent when clicked again while EDGE provisions the first.
