Breaking: the scene container is renamed View across the API (`SceneId` → `ViewId`, `SceneStore` → `ViewStore`, `SceneKind` → `ViewKind`, `Scene` → `View`, `SceneBuilder` → `ViewBuilder`, `useSceneProjection` → `useViewProjection`, the store's `scenes`/`scene(id)` → `views`/`view(id)`) and the `frame` node type to `view` (`FrameNode` → `ViewNode`, `isFrameNode` → `isViewNode`), with stored `frame` nodes read as `view`; react-ui-canvas-compute and plugin-canvas's model follow (`boardSceneId` → `boardViewId`, `readScenes`/`writeScenes` → `readViews`/`writeViews`, `ROOT_SCENE_ID` → `ROOT_VIEW_ID`). Panning the canvas no longer re-renders its panels and toolbars. The canvas's selection, editing and tool commands live in a `CanvasController` (`createCanvasController`) that reads its state when a command runs. A new `ViewsInspector` shows a drawing's views, nodes, links and placed objects as a tree. Group (⌘G) now makes an anonymous Object and one Instance in place of the selection, joining the Objects library once named or placed again, and Ungroup (⇧⌘G) puts it back, deleting an anonymous definition; `groupIntoView` and the Objects panel's Compose button are removed, and deleting the last node that opens a View or an anonymous Object deletes that record too, as do stores on load (`createMemoryStore`'s `root` option, plugin-canvas on bind). Group and New class from selection move to the inspector panel's toolbar (`InspectorPanel.Root` takes `actions`), a `cloud` node type (tool key C) joins the built-in shapes, drawn through a new `NodeDef.silhouette` outline, the timeline's key and auto-key actions move into one menu, and the scene-tree test fixtures move from `builder/testing` to `testing`. In react-ui-list, a Tree in multiple-selection mode opens its branches from the disclosure again, and `Tree.Content` takes `scroll={false}` to leave scrolling to an outer container. The inspector panel shows the same sections docked or floating: `InspectorSectionDef.show` and `InspectorPanel.Root`'s `selected` are removed.
