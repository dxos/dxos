Comments on a spec work end to end. A comment notification about a spec opens the spec's project with Comments beside it, since a spec has no node of its own: notifications open their object where the plugin that owns it places it. A spec's type names the feature-map skill, so the agent answering a comment on a spec can edit its blocks.
