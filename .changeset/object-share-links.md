Any Composer object can be shared from a Share dialog with a link that joins the recipient to its space in the background — creating an identity first in a fresh browser — and shows the object before the join completes: the client opens the space from what EDGE serves for the link's invitation (`ClientOptions.bootCache.pendingSpaces`, listed as `space.internal.provisional` until the services list it). `client.spaces.join(invitation, { syncScope })` joins a space replicating only the given objects, `space.internal.extendSyncScope` widens it, and a delegated invitation's `sharedObjectIds` are written beside it as a `DelegatedInvitationScope` credential that EDGE serves them by, with the space root, to a request signed with the invitation's guest key (`EdgeHttpClient.readSharedObjects`); the replication scope is enforced by the joining client only, not by EDGE or other members. `InvitationEncoder.toJson`/`fromJson` carry an invitation's shareable fields as JSON, as share links do. ECHO queries no longer wait for indexing: objects in documents the index has not read yet are read from disk, and a live query updates once the index catches up. `Ref.load` no longer misses an object whose parent's document is still loading.
