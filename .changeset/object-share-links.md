Any Composer object can be shared from a Share dialog with a link that joins the recipient to its space in the background — creating an identity first in a fresh browser — and opens the object as soon as the space appears; until then its plank shows the object read-only from an in-memory, read-only ECHO client over the documents EDGE hands to the link's invitation before the recipient has an identity (`EdgeHttpClient.readSharedObjects`, rendered through the new `AppSurface.PendingArticle` role and `AppSurface.ArticleData.readonly`). `client.spaces.join(invitation, { syncScope })` joins a space replicating only the given objects, `space.internal.extendSyncScope` widens it, and a delegated invitation's `sharedObjectIds` are written beside it as a `DelegatedInvitationScope` credential that EDGE serves them by; the replication scope is enforced by the joining client only, not by EDGE or other members. `InvitationEncoder.toJson`/`fromJson` carry an invitation's shareable fields as JSON, as share links do. ECHO queries no longer wait for indexing: objects in documents the index has not read yet are read from disk, and a live query updates once the index catches up. `Ref.load` no longer misses an object whose parent's document is still loading.
