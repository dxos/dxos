The Bramble sample space is now organized around four projects: Spring Blend Launch, Q2 Sourcing Trip, Olive & Vine Onboarding and Roastery Ops.

Each project has its own tasks, artifacts and agent instructions, and at least one unassigned task written as a brief an agent can take on. Project artifacts are all documents and drawings, which production renders; the mailbox is bound as chat context, so the projects read the same with the inbox plugin off. Roastery Ops owns a weekly roast-report routine that ships disabled.

A Reference collection owns the company records several projects list as artifacts, and a Roastery Handbook collection points at documents the projects own. The tour now leads with projects, and contradictions in the sample data (lot numbers, the Spring Blend's components, roaster size) are fixed.
