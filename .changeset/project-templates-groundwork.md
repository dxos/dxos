Add project templates: plugins can contribute pre-wired Project scaffolds (instructions, skills, standing context, starter routines) via a new template capability. The mailbox gains a "Set up project" action (Inbox Research), CRM contributes a sender-research project, and the brain plugin contributes a scheduled mailbox fact-analysis project. Projects created from a mailbox routine now run with the project bound into their session scope so outputs can be filed into the project's artifacts.
