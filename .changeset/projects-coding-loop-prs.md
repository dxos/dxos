A task handed to a coding agent now ends in a draft pull request, and a cloud coding run can start without Composer open. The delegation brief asks the agent to commit on a new branch, open one draft PR per repository it changed, attach each PR to its task and move the task to `review`; it never pushes to the default branch, and merges only once the person approves. `ProjectOperation.UpdateRepositories` (key `org.dxos.operation.projects.updateRepositories`, previously plugin-code's `org.dxos.operation.code.updateProjectRepositories`) joins the project skill, so MCP clients can give a project its repositories. plugin-claude adds the Cloud Coding skill (`/cloudCoding`): `startCloudRun` hands tasks to Claude Code on EDGE and `syncCloudRun` folds its progress into the chat, importing and attaching the pull requests it opened when the turn ends, and takes a follow-up `prompt` (an answer, or the approval to land) that continues the agent in the same chat, moving the tasks to done once every pull request has merged; plugin-claude now ships as an EDGE plugin. `@dxos/plugin-projects/Delegation` exposes the host-neutral half of delegation, `@dxos/edge-compute/host-process-manager` drives EDGE processes over a host service, `EdgeAgent.runTurnUntil` folds a turn up to a deadline and leaves it open for the next call, and an operation on EDGE now gets `Credential.AccessTokenResolver`, so it can lend a server-custodied token (a GitHub App installation's).
