Projects gains feature maps: `Feature` (status, two-level subfeatures, repo spec links, `DependsOn` and `Implements` relations), `Showcase` (a write-up with artifacts that `Demonstrates` a feature or task) and `FeatureMap` (a board with cards and canvas views), with operations agents use through the project skill. The canvas dynamic projection now accepts a node factory, a link style with arrow ends, and its own capabilities, so a host can render its own nodes in a drag-only view.
