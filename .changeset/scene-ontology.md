`@dxos/scene` exports `Ontology`, one registry of every schema a stored drawing is made of: the document, scenes, layouts, models, elements, nodes, links, styles and diagram shapes. `moon run scene:gen-ontology` writes the whole ontology as one JSON Schema document, `ontology.schema.json`, and the docs page that lists every type.
