'@dxos/react-ui': minor

- HALO and join dialog steps (identity input, profile form, reset confirmation) show their validation message again: the field is marked invalid whenever a message is present, which the field's error text requires before it renders.
- `SceneView.Root` takes `onReadonlyChange`; when given, the palette's tools group (below Pan) gets a lock toggle between looking at the scene and editing it. Turning read-only drops a drawing tool back to select.
- The canvas's properties, layers and about panels are now **inspectors**. **Breaking (`@dxos/react-ui-canvas`):** `SceneView.Root`'s `panels` prop is renamed `inspectors`, and `PanelMode` is renamed `InspectorMode`. `SceneView.Root` also takes `onInspectorsChange`; when given, the dock gets a toolbar whose close button floats the inspectors, and each inspector's menu docks or floats them. `Properties`, `LayersPanel` and `About` take `onDockedChange` for that menu item, and `useInspector`/`InspectorDef` let a host add its own inspector. In Composer, the canvas drawing's "Dock panels" / "Float panels" menu item is removed in favour of these controls.
- The smart line leads the palette's link tools and is the link a port drag creates until another link tool is picked. The bottom camera and action bars use full-size icons, as the palette does; the centred action bar keeps clear of the camera bar and scrolls when the view is narrow.
- Fixed: editing a conductor circuit (dropping a shape, moving or linking one) threw `Unknown property`. `CanvasBoard.layout` declared closed graph nodes and edges while boards store each shape's `center`, `size` and `text` and each connection's `input` and `output` beside them; the layout's elements are now open records, so ECHO accepts the writes.
- Fixed: a conductor circuit's graph never ran in Composer (a switch did not light its beacon): its runtime asked the space for services no layer spec provides there. The circuit now takes the app's operation invoker, builds the operation registry over the space's database and the app's operation handlers, and resolves the ECHO type registry; the runtime adapter is typed rather than cast, so a missing service is a type error.
