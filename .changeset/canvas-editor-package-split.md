The scene UI is now two packages: `@dxos/react-ui-canvas` is the 2D and 3D surface (with `/3d`, `/io` and `/headless` entries), and the new public `@dxos/react-ui-canvas-editor` is the editor (`SceneEditor`, panels, inspectors, tools), with breadcrumbs, drill-in to nested frames, Neu Light and Neu Dark themes, and a Timeline hidden until toggled; `@dxos/scene` is now public. Breaking: `@dxos/react-ui-scene` is removed, and plugin-canvas migrates legacy scene drawings onto `Canvas` objects when a space loads and drops its legacy canvas surfaces; `@dxos/plugin-canvas/Architecture` now exports `canvasDrawingSchemas`, `loadDrawingCanvas`, `readDrawingContent` and `editDrawingContent`. The Create Drawing dialog now lists every installed renderer the first time it opens, not only svg. `@dxos/plugin-spacetime` is removed; a 3D canvas (`@dxos/plugin-canvas`) now does its work. A 3D canvas places primitives, library objects and imported meshes, joins, subtracts and extrudes them as solids, imports OBJ and GLB files as library meshes and exports STL. Spacetime scenes are not migrated. `@dxos/plugin-canvas/MeshPresets` provides the bundled vehicle models (fire truck, race car, taxi) as mesh objects, and the Demo space template's line-up is now a 3D canvas. A frame on a canvas that shows a drawing as a card now fits the drawing to the frame (`CardData.extrinsic`), and an object opened outside any collection (`…/db/<type>+<id>`) resolves again: the app graph no longer wraps a type node's schema in an action forwarder.
