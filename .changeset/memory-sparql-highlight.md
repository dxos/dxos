The Memory page shows each query's SPARQL with syntax highlighting. The Brain skill steers open-ended questions toward what the content says: survey the predicates and entities first, group by topic, report themes in aggregate without naming people, and read a negated fact as the source's own negation. A new Community Findings project template holds five analysis tasks that each name the artifact their answer goes in (four sheets with charts and a docs-gap brief), and a deck task that presents them; with a community's memory imported, the agent answers each task from the memory and files the artifact on it.
