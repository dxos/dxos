`ChatPlane` is exported as `@dxos/plugin-assistant/ChatPlane`, and `ChatPlane.Cell` takes a `title`. A chat model given a subagent's thread now shows that thread alone, so each subagent can be rendered in a column of its own. `AssistantCapabilities.ModelPreset` lets a plugin offer models beyond the built-in catalog in the chat's model picker.
