Composer's context menu replaces the browser's everywhere: right-click opens the node's actions, then the clipboard and link actions the browser would have offered, a container's undo and redo (registered with `AppNode.registerEditCommands`), and Home, Back and Forward. An inline object preview in a markdown document shows its label and open button together, inset at the bottom, only while hovered.
