Adds the Ride Check space template: a written `.mdl` spec of a ride-forecast page, a feature map with one card per feature, and three tasks for the assistant (draw the architecture, build and deploy the Worker, check the live page). The project instructions carry the recipe for a Vite page built with `@dxos/react-ui` and served by one Cloudflare Worker over the Open-Meteo API. The space icon picker gains a bicycle.
