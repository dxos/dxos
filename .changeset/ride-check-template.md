Adds the Ride Check space template: a written `.mdl` spec of a ride-forecast page, a feature map of four features carrying the spec's requirements (the verdict with two subfeatures), and three tasks for the assistant (draw the architecture, build and deploy the Worker, check the live page). The project instructions carry the recipe for a Vite page built with `@dxos/react-ui` and served by one Cloudflare Worker over the Open-Meteo API, deployed with the space's Cloudflare connection and kept in a local sandbox's workspace when no repository can be attached. The space icon picker gains a bicycle.
