The slide editor's preview is one toggle: the toolbar button shows or hides the rendered slide below the markdown, and the preview pane carries a close control that does the same thing. The separate "preview in the companion" button is gone, and with it the mode it selected. The preview is the editor's own pane, so the control no longer touches the plank's companion at all — it neither opens one nor closes one another tool put there.
