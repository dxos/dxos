# effect-4-schema-ast spike

Standalone spike proving (a) ECHO's `SchemaAST` helpers can be ported to Effect 4 and (b) JSON
Schema persisted by Effect 3 can be read back into Effect 4.

**Not part of the pnpm workspace** — it pins `effect@4.0.0-beta.105`, which conflicts with the
catalog's `effect@3.21.4`. `agents/` is outside every workspace/knip/moon glob, so nothing here
affects the monorepo build.

```sh
cd agents/superpowers/spikes/effect-4-schema-ast
npm install
npm test        # 106 tests
npm run typecheck
```

Findings and recommendations: [REPORT.md](./REPORT.md).

`fixtures-v3.json` (2 hand-built types) and `corpus-v3.json` (all 18 ECHO types exported by
`@dxos/types`) were both generated by running `@dxos/echo`'s `toJsonSchema` on HEAD
(effect 3.21.4); regenerate them from a temporary test inside the owning package if the stored
format changes.
