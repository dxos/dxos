# @dxos/react-ui-query

Editors for ECHO queries: `QueryEditor` (a CodeMirror input for the query language, with autocomplete) and `QueryForm`
(a structured type/tag picker), plus `useQueryBuilder`. Kept apart from `@dxos/react-ui-components` because they carry
the CodeMirror stack and the `@dxos/echo-query` grammar.
