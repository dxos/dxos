# DEUS for VS Code

Highlighting for `.deus` files, and for ```deus fences in Markdown and `.mdl` documents.

```bash
# from this directory: link it into VS Code's extensions folder, then reload the window
ln -s "$PWD" ~/.vscode/extensions/dxos.deus-vscode-0.1.0
```

The grammar is TextMate (`syntaxes/deus.tmLanguage.json`), so it also works in any editor or
renderer that reads TextMate grammars (Shiki, GitHub Linguist, Sublime).
