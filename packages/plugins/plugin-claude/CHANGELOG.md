# @dxos/plugin-claude

## 0.12.0

### Minor Changes

- ffbd4dc: Add the Claude plugin: a `ClaudeManagedAgent` type for configuring an Anthropic-hosted managed agent, a `ClaudeAgentSession` type recording each run, and an assistant skill that can create, deploy, run and read back those agents.
- d536507: Rename the Claude plugin's skill and events entry points to `ClaudeSkill` and `ClaudeEvents`, and declare Tasks as a dependency of the Projects plugin so enabling Projects enables Tasks with it.

### Patch Changes

- a112889: Tell the Claude Agents skill that managed agents compact their own context, so out-of-context warnings in a transcript are not a reason to restart a session.
