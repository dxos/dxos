# @dxos/plugin-uml

UML for Composer drawings:

- **The UML skill** — the assistant draws class diagrams in any drawing (tldraw, excalidraw, svg or canvas)
  through plugin-illustrator's drawing operations.
- **The class shape** — a UML class (name, attributes, methods) for the canvas renderer, contributed to
  plugin-canvas through `CanvasCapabilities.NodeType`.

See [docs/DESIGN.md](docs/DESIGN.md).
