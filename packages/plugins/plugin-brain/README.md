# @dxos/plugin-brain

The Facts layer for Composer: operations over the RDF `Fact` tuples the space's agents know, which live
in each agent's brain (`plugin-agent`'s `BrainService`). Provides mailbox fact extraction into an agent's
brain, assistant tools for querying and summarizing facts, and a `FactViewer` companion surface.

See [PLUGIN.mdl](./PLUGIN.mdl) for the specification.
