# @dxos/plugin-recorder

Record the voice-over (and optionally a screen or camera video) of a plugin-presenter deck while presenting it,
reading each slide's speaker notes. Takes are stored as plugin-studio media artifacts and listed in the
presentation's Recordings companion.
