# MINDMAP PLUGIN DESIGN

## Premise

A freeform documentation/design tool where you can place multiple documents as nodes onto a page, and specify groupings or relations between them.

## Features

- A visual map "page" to fill with nodes, drawings, and text notes
- Nodes, which are representations of documents
- Titles for nodes that appear within the node shape
- Importing documents into a map as nodes
- Zooming in to a node, to view the document it represents
- Dragging and dropping objects around the map
- Drawing lines/arrows between nodes, and annotating them
- Drawing boxes/other shapes on the map, and annotating them
