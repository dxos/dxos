# @dxos/plugin-ste

Simplified Technical English (ASD-STE100) for the Composer assistant:

- **The STE skill** — the assistant writes and rewrites technical text in STE: procedures, error messages,
  manuals and reports.
- **The verify tool** — `SteOperation.Verify` finds violations of the writing rules (sentence length, verb forms,
  passive voice, banned helping verbs, contractions, semicolons, paragraph length) and lists the words that are
  not in the approved word list.

See [docs/DESIGN.md](docs/DESIGN.md). The rules and word list come from the repository's
`simplified-technical-english` agent skill; see [docs/NOTICE.md](docs/NOTICE.md) for copyright.
