# @dxos/plugin-handpan

Handpan music notation and real-time note detection for Composer.

- `src/audio` — instrument-neutral audio analysis: onset detection (spectral flux), pitch
  detection (McLeod Pitch Method), and calibrated note classification.
- `src/components/Tuner` — calibration and live note display.

See [`docs/DESIGN.md`](./docs/DESIGN.md) for the design and roadmap.
