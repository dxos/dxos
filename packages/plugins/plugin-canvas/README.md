# @dxos/plugin-canvas

Infinite multi-depth canvas, contributed to the illustrator plugin as a drawing variant
(`dxos.org/scene/1`). The engine lives in `@dxos/react-ui-canvas/scene`; this plugin binds it to
ECHO (`Drawing.Canvas.content` as one record per scene, node and link) and maps the illustrator
scene DSL onto it, so agents can draw on the canvas through the illustrator operations.

Design: `packages/ui/react-ui-canvas/docs/DESIGN.md`.
