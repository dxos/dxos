From a question to a picture in one turn

Agents describe systems well and draw them badly. drawing splits the job: the agent says what connects to what, and a layout engine decides where everything goes.

  1. Install the skill

    One command teaches your agent the diagram language and the drawing command.

  2. Ask for a diagram

    “Draw how a request moves through our services.” The agent reads the code and writes the .dx file.

  3. Get an SVG

    drawing lays it out in about a second. Put the SVG in a README, a pull request or a design doc.

Say what's related, not where it goes

Name the relationship and the right arrowhead follows. There are no coordinates to get wrong; add a placement hint only when you want one.

The SVG is the drawing

A .dx.svg is an ordinary image, and it also carries everything needed to edit it again. Nothing is locked in a service you have to log in to.
