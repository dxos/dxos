# Product Hunt

**Name:** drawing.sh

**Tagline (60 chars):** Your coding agent writes it. drawing lays it out.

**Description (260 chars):**
A skill and CLI that let coding agents draw architecture diagrams. The agent writes a few lines saying
what connects to what; drawing places the boxes, routes the arrows, reports crossings and writes an SVG
for your README, PR or docs.

**Topics:** Developer Tools, Artificial Intelligence, Design Tools

**Gallery:** demo video, hero diagram with its source, relationships grid, a README with an embedded
diagram.

**Maker comment:**

Hi Product Hunt! We build Composer, a local-first workspace where people and AI agents edit the same
documents. Inside it is a diagram layout engine we got tired of keeping to ourselves.

drawing.sh is that engine as a skill any coding agent can use. Install it with one command, ask
"draw how a request flows through our services", and you get a clean SVG instead of Mermaid spaghetti.
The agent reads the layout report and fixes its own crossings.

Import the file into Composer and it becomes a live canvas your team and your agents keep editing.
We'd love to hear which diagrams it draws badly.
