**Title:** Your coding agent can draw now: drawing.sh in 60 seconds

**Description:**

drawing.sh is a skill that lets coding agents draw architecture diagrams. The agent writes a few lines
of text saying which boxes exist and how they relate; drawing places them on a grid, routes every arrow,
reports crossings, and writes an SVG you can drop into a README or a pull request.

In this video:
0:00 Install the skill
0:10 Ask the agent for a diagram
0:25 The agent writes the .dx source and renders it
0:40 Edit one line, the layout re-flows
0:50 The SVG carries its source; import it into Composer

Install: npx skills add dxos/dxos --skill drawing
Site: https://drawing.sh
Source: https://github.com/dxos/dxos/tree/main/packages/devtools/drawing
