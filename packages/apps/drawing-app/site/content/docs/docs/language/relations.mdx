A **relation** is a word in place of `->` that says what an edge means. drawing.sh draws the marker that word means
in a class or data-model diagram. The left end is always the child, the whole, the owner or the "one" side.

**Example** (Drawing inheritance)

```dx
node Animal
node Dog
edge Dog extends Animal
```

`Dog` is on the left because it is the child.

| Statement                          | Draws                                          |
| ---------------------------------- | ---------------------------------------------- |
| `edge Dog extends Animal`          | A hollow triangle at Animal.                   |
| `edge Store implements Readable`   | A dashed line and a hollow triangle.           |
| `edge Car composes Engine`         | A filled diamond at Car. The parts die with it. |
| `edge Team owns Player`            | A hollow diamond at Team.                      |
| `edge Customer one-to-many Order`  | A bar at Customer and a crow's foot at Order.  |
| `edge Student many-to-many Course` | Crow's feet at both ends.                      |
| `edge App depends-on Logger`       | A dashed line and an open arrow.               |

A relation edge takes a label like any other: `edge Customer one-to-many Order "places"`.
