---
title: Layout hints
description: Fix one thing you saw in a layout with the smallest hint.
---

Start with no hints. drawing places every box and routes every arrow on its own, and its report counts the
crossings and bends. When the picture has a defect, fix that one defect with the smallest hint, render again, and
look. If a hint makes the report worse, remove it rather than adding a second one to fight it.

## Placement

```dx
node Api "API server"
node Db "Postgres" below Api
node Cache "Redis" right-of Db
```

`right-of X`, `left-of X`, `below X`, `above X`, `same-row X` and `same-col X` place a box against another. Each is
a rule the layout must keep; prefix `~` (`~below X`) to make it a preference the layout may break.

Groups take the same words. Relate groups to each other (`group data below web`) rather than relating members of
different groups, or the frames stretch around empty space.

```dx
group web "Web app" {
  node Browser
  node Api
}
group data "Storage" below web {
  node Db
}
edge Browser -> Api
edge Api -> Db
```

## Shape

A diagram that came out as a long strip:

- `diagram aspect=16:9` asks for a wider, shorter picture.
- `compact` on a group keeps it near square, and `max-width=N` limits it to N columns.

```dx
group services "Services" compact max-width=3 {
  node Auth
  node Billing
  node Search
  node Mail
}
```

## Sides

An arrow that wraps around a box can be pinned to a side of each end: `top`, `bottom`, `left` or `right`.

```dx
node A
node B below A
edge A:right -> B:top
```

`A:~right` prefers the side without requiring it.

## Gutters

```dx
node A
node B below A
node C below B
node D right-of B
edge A -> C via cell(1.5,_)
```

`via cell(1.5,_)` routes an edge through the gutter between columns 1 and 2, and `via cell(_,1.5)` through the
gutter between rows 1 and 2. Use it when several arrows crowd one gutter.

## Buses

```dx
node Api
node Db
node Cache
node Queue
edge Api -> Db, Cache, Queue bus
```

`bus` draws one trunk from the source that splits to each target, in place of separate arrows.
