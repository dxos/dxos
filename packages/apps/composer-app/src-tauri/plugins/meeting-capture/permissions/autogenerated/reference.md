## Default Permission

Meeting detection and system-audio capture for the meeting recorder.

#### This default permission set includes the following:

- `allow-get-support`
- `allow-list-mic-apps`
- `allow-start-detection`
- `allow-stop-detection`
- `allow-start-system-audio`
- `allow-stop-system-audio`
